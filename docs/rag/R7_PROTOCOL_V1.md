# R7：口语强度与歧义分层实验预注册 v1

日期：2026-09-20。只建立实验，不自动变更生产默认策略。数据、协议、代码与模型标识在首次远程调用前冻结。

## 1. 研究设计

对同一个信息需求构造双语分级输入：L0为原始规范问句；L1为套话和轻度口语；L2用日常词替换部分专业术语但保持可识别；L3强替换和绕话但仍有足够机制与条件恢复原信息需求。L0–L3共同用于检索质量评价。L4故意丢失区分条件，使多种解释合理，是独立的歧义维度，不当作可恢复口语程度的连续第5点。

L4只评价需要澄清的识别，不拿作者心中的原答案当唯一正确意图，不和L0–L3的质量混合。模型输入只包含当前文本、语言及统一本科计算机领域提示，绝不包含人工level、canonical、family、相关资料或答案。不同档位的测试冠军只能作为分层描述；没有实现输入分级器，不得按人工level路由后声称上线收益。

## 2. 数据与标签

从已有固定版本的 Hello Algo 中文教材和 OpenDSA 英文教材12份全文构造12个信息需求family，每个有英文和中文规范问题，五组共120输入。基础问题与证据span为AI辅助暂定标签，非教师人工金标。来源真实不等于标签人工。构造口语变体的助手只看规范问句，不读资料、答案和检索结果；另一遍审核检查L0–L3意图保持和L4确有两个以上合理解释。

资料包含12篇课程原文及R5的207篇公开软件主题干扰材料。课程原文按固定256-Qwen-token无重叠递归切片，标题路径编码；干扰材料复用原236切片及向量。评分span为完整原文事实句/段落，保留起止位置和哈希，不是穷尽相关性。部分需求仅有一种资料语言支持，但输入两种语言；主实验只做混合语料检索，不把缺少另一语料的方向记成跨语言失败。

同一支持文档关联的family合并为分量，按 SHA256('r7-split:'+component) 排序，前max(1,floor(count/3))分量为dev，余下test。两种语言及所有level始终跟随family。同一教材中的不同章节仍可能相关；文档分量不是独立教材。来自两本教材的局部主题/文档留出不能称为未见教材泛化。实际分量数量在freeze记录；bootstrap仅作小样本探索。

## 3. 固定四臂

| 臂 | 行为 |
|---|---|
| original | 原文直接进行向量＋词汇检索，没有LLM澄清识别 |
| conservative | 独立LLM提示，仅去口语套话、压缩表达，保留已有技术词，不补充新术语；识别缺失意图则clarify |
| normalize | 独立LLM提示，在意图足够明确时把日常机制描述映射为标准CS术语并保留约束；多种解释无法区分则clarify |
| dual | 使用与normalize相同的模型输出，原文与normalize两路原文优先交替去重，总共最多20；normalize要求澄清时同样clarify |

文字模型为deepseek-flash，temperature=0，thinking disabled，最多320输出token，返回query、needs_clarification、reason。成功标记澄清时忽略其query，不因缩短原文而把一个有效澄清标记改判失败；这项规则在R7开始前确定，不回填R6。JSON/数字/代码/基本语言校验失败时采用原文回退，失败原始响应保留。字面量检查不是完整语义保证。

查询编码采用qwen/qwen3-embedding-8b，固定CS前缀；有界dense+lexical混合、metadata weight 0、最多20候选。四臂使用同一语料、向量、预算。按SHA排序的去重查询输入批量16编码，以减少请求；批量墙钟和输入数单列，不能冒充单查询在线延迟。

## 4. 指标、选择与共享重排

主算法指标是首阶段已知证据span Hit@5；次指标Hit@1、Hit@20和MRR@20。Hit用返回片段联合覆盖完整至少一个span；MRR使用单片段完整覆盖。每个未歧义输入若被错误澄清，所有质量记零，不能删去。向量失败也保留分母。

只根据dev L0–L3的平均Hit@5、再MRR@20选一个全局策略；完全平局按original、conservative、normalize、dual顺序优先省调用/简单的路径。在任何test候选排名前写入选择锁。test全部臂与分层结果仍完整呈现，不反向选策略或调prompt。

为避免重排API失败在不同臂制造假增益，每条L0–L3输入将四臂各最多20候选组成去重并集（最多80），用原文查询做一次qwen/qwen3-reranker-8b共享评分；再按同一评分对每臂自身候选排序，取Top5组装1024源token预算。shared评分失败时所有需要检索的臂共同记最终失败、证据Hit和MRR为0；首阶段指标不变。L4不调用重排。

这是受控共享评分实验，不是现有生产每次只重排20条的端到端测量，不能将其费用/延迟当作部署值，也不假定托管端点在不同batch下必然不变。报告最终post Hit/MRR作为辅助结果，不覆盖首阶段主结论。

歧义指标：L4中clarify占比，以及L0–L3中的误澄清占比；原文baseline没有检测器，L4为0不等于已证明其返回全部错误。程序失败导致的原文fallback不是成功澄清。另报语言、档位、实际改写、机械校验、回退及语义风险。记录各档中原文相对同family-language L0的退化，不假定必然单调。

按支持文档关联分量配对bootstrap，2000次、种子20260920，分量内全部语言/level同时抽样；报告差值、区间和改善/受损数。测试分层比较为探索，未作多重校正。各档样本相关，不能以120作为独立信息需求样本数。

## 5. 故障、计费与复现

每个logical request对于HTTP429/502/503/504仅允许1次重试，间隔1秒；超时或不确定中断不盲目重试。HTTP attempts分别记录logical_key、attempt=1/2、首次状态和最终状态。最多480个text attempts、120个embedding attempts、192个rerank attempts；逻辑text至多240、shared rerank至多96。并发text=2、embedding=4、rerank=2，超时60秒。

OpenRouter已报告金额阈值4美元，每个在途请求预留0.02美元，实际每次HTTP attempt均占请求上限。此为客户端预请求护栏，非服务端硬账单限额。HTTP200缺少cost则停止后续请求，历史缺失状态不得通过重启绕过；非200缺金额仍记未知。DeepSeek无金额则只报告token，不能计成免费。

文档编码若失败，不对缺文档语料评分；查询失败保留。文档缓存必须核验完整输入哈希、模型签名、文件哈希和4096维。只发送公开查询与资料。保留冻结代码、原始响应、候选、共享分数、逐题结果、选择锁、环境和费用；提供禁用网络的离线重算，不覆盖R6，不把不同轮百分比直接相减。

R7需要回答的是在这些人工构造强度下哪种策略有支持证据，不能保证发现普遍最强方法。如果没有明确赢家，如实保留负结果和当前配置。
