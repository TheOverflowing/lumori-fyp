# RAG 优化过程与结果

本记录服务于中英文计算机本科课程的检索研究。只报告已保存证据支持的实现与读数；真实课程效果、教师标注和学生学习效果分别记录，不从软件测试或自编数据外推。

## 2026-09-12 · R0：固定原始基线

优化前管线为：资料解析 → 1200 字符切片、120 字符重叠 → OpenRouter 嵌入与 SQLite 缓存 → 学习目标原文嵌入 → 所选课程／资料内 cosine Top 5 → DeepSeek 生成与难度复核。原始配置、检索代码与依赖文件已保存为 [基线快照](baselines/dense_v1_20260912/manifest.json)。原先没有经过相关性标注的数据集，不能追写一个未经测量的“历史召回率”。

新增纯函数检索模块，保留 dense_v1 并实现 bm25_v1、hybrid_rrf_v1、hybrid_mmr_v1。四种策略共用课程边界、索引兼容检查、来源记录与生成门禁。BM25 没有匹配时在调用文字模型前返回证据不足。诊断分数保留在任务证据中，不加入生成与难度复核的模型输入。

固定参数：每路候选 20，RRF 常数 60、两路等权，MMR 在融合前 20 中重排且权重 0.7；BM25 k1=1.2、b=0.75。直接嵌入原文，不增加查询指令。本轮只比较排序，使用同一批真实返回的 4096 维 Qwen 向量。

### test：14 条可答查询

| 方法 | Recall@5 | 完整必要证据率@5 | nDCG@5 | 相对基线的 Recall 差 |
| --- | ---: | ---: | ---: | ---: |
| dense_v1 | 90.48% | 100.00% | 93.30% | — |
| bm25_v1 | 46.43% | 50.00% | 61.22% | −44.05 个百分点 |
| hybrid_rrf_v1 | 46.43% | 50.00% | 61.40% | −44.05 个百分点 |
| hybrid_mmr_v1 | 46.43% | 50.00% | 59.92% | −44.05 个百分点 |

三种候选的 Recall@5 均为 0 条改善、3 条持平、11 条退步；相对变化为 −48.68%，不能与 −44.05 个百分点混用。配对查询 bootstrap 95% 探索性区间为 [−59.55, −28.54] 个百分点（固定种子 20260912，2,000 次）。这个区间只描述本试点，不构成真实课程的总体显著性结论。

dev 的 Recall@5 为 dense 98.21%，其余均 46.43%；各候选均 0 条改善、2 条持平、12 条退步。没有通过合并 dev/test 来替代 test 报告。三候选 Recall@5 恰好相同，不表示它们的所有排名相同；nDCG@5 与 Recall@10 已显示差别。

Recall 包括所有正相关片段，完整必要证据率只要求每个必要答案部分至少命中一个允许来源。因此 dense 的 90.48% Recall 与 100% 完整证据率不矛盾：遗漏可能是部分相关的补充材料。

### 失败分析：跨语言来源被挤出

全体可答查询的分组诊断（不是单独 test 结果）：

| 类别 | 查询数 | dense Recall@5 | RRF Recall@5 | dense 完整证据率@5 | RRF 完整证据率@5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 术语匹配 | 7 | 92.86% | 71.43% | 100.00% | 100.00% |
| 语义改写 | 7 | 100.00% | 57.14% | 100.00% | 100.00% |
| 跨语言 | 7 | 92.86% | 7.14% | 100.00% | 0.00% |
| 多证据 | 7 | 91.67% | 50.00% | 85.71% | 0.00% |

具体案例 `q18`：中文问题的唯一标注来源为英文片段 `db10`。它的向量排名为第 1、cosine 约 0.713665，词法匹配为 0；中文片段 `db05` 的向量排名为第 2、cosine 约 0.503457，BM25 排名为第 1，因而成为 RRF 第 1。保存的 RRF 前 10 均为中文双路入榜候选，正确的英文片段未进入前 10。可在 [逐题排名](experiments/20260912T053716373758Z/rankings.json) 和 [冻结标注](experiments/20260912T053716373758Z/dataset.json) 核对。

预设参数存在可以直接推导的倾向：任何双路前 20 候选的 RRF 分数至少为 `2/(60+20)=0.025`；任意单路候选至多为 `1/(60+1)≈0.016393`。只要双路交集足够大，单路第一名也会被交集候选压后。跨语言的正确证据缺少字面匹配时，可能因此受损。该数学性质及上述排名支持“本配置中过度偏好双路重合”的解释；不能据此断言所有混合检索都会退步。后续仍需通过独立改动和更多经过审核的数据检验。

当前没有检索级拒答阈值，四种方法对 4 条不可答查询都返回了非空结果；这些结果独立记录，不进入 Recall 分母，也不能直接解释为生成幻觉率。

### 本轮决策与下一轮问题

本轮没有证明召回提升，候选均不替换生产默认值。成果是建立了可复现的比较基线、留存真实负向结果，并定位到值得单独验证的跨语言词法干扰问题。

下一轮优先考虑：在更充分且经过人工复核的课程数据上，比较保留高相关向量候选的融合方式、词法信号门槛或权重。之后分别研究查询任务指令、切片／上下文补全和专用重排。每次只改变明确的因素，保留失败与退步。当前 test 已经被查看，不能在反复调参后继续称为未见测试集；确认性结论需要新的独立保留数据。

## 2026-09-12 · R2：真实材料、公开人类标签与有界词法加分

已保存 Hello 算法与 OpenDSA 中英各 6 篇原文、许可证、固定版本与 80 个片段。教材本身尚无课程检索人工标签，因此建立了 [人工标注包](../../benchmarks/rag/course_sources/ANNOTATION_GUIDE.md)；空表不能转换为 human_reviewed。

独立导入 MLQA 中英计算机知识子集（81 片段、92 查询）和 T2Ranking 中文技术网页子集（339 片段、20 查询）。MLQA 正例由原人工答案跨度转换；T2 继承公开人类标签的二值版本。助手筛选主题不算新增人工相关性标注，两者也不能混称大学教材检索金标准。

在新数据首次排名前固定 `hybrid_dense_lexical_v1`：两路候选并集，以 cosine 为基础，归一化 BM25 最多增加 0.05。既有四种方法公式不变。MLQA test 的已知正例 Recall@5 从 dense 的 91.25% 到 91.875%（+0.625 个百分点）；T2 本地 test 从 40.58% 到 44.74%（+4.17 个百分点）。T2 的等权 RRF 为 47.02%，比新方案更高；新方案 T2 MRR@5 从 73.33% 降到 71.67%。完整退步、逐题结果和范围限制见 [R2 报告](EXTERNAL_DATA_RESULTS_20260912.md)。

这是同一数据集、同一向量下的本轮方法对照；不能把新数据结果与 R1 自编数据的读数相减作为提升。MLQA test 的 80 查询只有 40 个双语 family，T2 test 只有 10 查询；结果不支持泛化或统计显著声明。两个派生任务的 all_evidence@k 仅等价于 Hit@k，不代表复杂答案的全部必要事实。

两次真实运行共 36 次嵌入、0 次文字生成；两次归档离线重放均新增 0 调用，排名与指标完全一致。364 项 Python 测试通过。服务加载 retrieval-v2，默认保持 dense_v1，重启前后全部业务表逐行一致。证据见 [R2 验证记录](external-data-verification-20260912.json)。下一步在课程专属人工标签上验证语言、任务类型与融合策略的关系；不将当前已暴露的 test 反复调参后称为独立验证。
