## 具体问题

**AVL：内容正确，但多透露了追问没有询问的条件。** 追问询问失衡节点及其左重/右重状态。回复中的 `+2` 和“左重”可由 profile 中的数值及符号定义推出，`unknown=false` 在这一部分合理。回复还主动补充“其左孩子的平衡因子为 -1”。该内容虽然确实存在于 profile，却没有被实际问题询问；它能进一步区分两种旋转情况，可能让不够具体的追问得到超出其信息量的收益。此处没有直接泄露旋转顺序，但违反了模拟用户只透露实际追问所需信息的限制。

**Graph：引用是真实的，所声称的目标却不成立。** 追问给出两个选择：“检查起点连通分量是否遍历完整”或“判断整图是否连通”。profile 的任务是访问所有顶点，而且已经知道图不连通。回复却选择“想判断整个图是否连通”，再引用“任务要求访问整张图的每一个顶点”作为依据。访问所有顶点不等于判断是否连通，该引用不能支持所选择的意图。

这条 graph 问法没有提供与 profile 相符的选项。模拟用户可以据 profile 指出“都不是；图已知不连通，我要访问所有顶点”，若严格格式只允许选给出的选项，则应返回 unknown；不能为了顺着选择题而采用一个新的任务。因此本审核不会机械地把 `unknown=false` 一律判错，而将核心错误标为 **无根据的意图断言**。

## 对结果解释的影响

必须保留两条原始回复及原来的实验分母，不能用本审核建议的示例回答替换实际运行结果。若后续检索显示改善，也需要同时披露 AVL 的未询问条件泄露；若检索仍命中，graph 的意图错误也不会因此消失。当前审核不读取检索结果，不宣称这些缺陷实际带来了哪种排序变化。

应分别报告：追问是否有用、回复是否受 profile 支持、回复是否超出实际问题、改写是否忠实、最终是否检索到目标证据。精确引用检查只是最低限度的程序性检查，不能代替上述语义判断。后续如修订模拟器，应作为新的预先冻结实验，不能覆盖本轮结果。
