# 可选查询融合与精简设置

日期：2026-09-20。本文记录用户主动开启的产品功能，不是新一轮召回效果实验。

## 页面与偏好

左下角统一入口为“设置 / Settings”，同一窗口分为“生成”和“模型连接”。融合模式默认关闭；按用户 ID 保存在当前浏览器的本地存储中，不写入共用的服务端模型配置，不跨浏览器同步。本地存储不可用时仍可在本次会话切换。退出或换账号重新读取该账号的偏好。

生成页使用单行“生成前追问 / Ask before generating”及与资料开关一致的 switch，去掉附属说明。追问窗口只保留问题、可选回答、补充输入、可展开的原始目标和操作按钮。辅助技术仍能读到“不确定，按原输入继续”的完整操作含义。中英文、浅深色、44px 点击范围、键盘焦点、减少动态效果均沿用现有界面。

打开设置不调用模型、不重绘生成草稿。修改偏好使未提交的理解检查失效；新请求记录开关快照，已经提交的生成不随之后的偏好改变。关闭时不在序列化结果中增加默认字段，兼容旧任务配置、幂等请求和已有检查点。

## 检索路径

请求字段为严格布尔值 `query_fusion`，默认 `false`。关闭时沿用原有检索。开启时：

1. 校验所选课程、资料和索引，先完成原查询检索。
2. 最多一次文本调用，生成保守的同语言检索改写。提示版本 `query-fusion-v1-20260920`；只看用户原目标以及确有提交的追问问题、选项与回答，不看语料、排序或金标。
3. 对有效且不同的改写再做一次嵌入和检索。每路最多 `candidate_k` 个候选，使用 RRF（k=60）去重合并，再截断至同一个 `candidate_k` 总候选预算。同分按语料顺序处理。
4. 重排继续使用原目标或真实回答补充后的目标，之后沿用原上下文预算与生成流程。改写不替换教学目标、标题或作者输入。

每路内部仍使用配置中的向量/词法策略，外层原文与改写融合是另一层操作。融合输出的 `score` 保留原查询余弦；`selection_score` 单独标为 RRF 分数，并保存两路排名。不能把 RRF 分数解释为正确率或证据充分概率。

归一化通过通用提示约束，不穷举口语词典。格式、长度、部分数字/代码字面值和语言检查不能证明完整语义忠实。信息歧义、无效返回、相同查询或超时会回到原查询；第二路嵌入失败也回到原候选。索引配置在执行中变化仍终止任务，避免混用配置。用户选择“不确定”或按原输入跳过时不尝试猜测改写。

## 调用、恢复与追踪

最多新增一次文本调用和一次嵌入调用，各自本地等待超时为 20 秒，无自动重试。实际文本输出 token 上限沿用服务端文本模型设置；20 秒不是远端费用上限或取消保证。所有调用沿用账号用量台账，Agent 预检为这两次调用留出预算。

`query_fusion_decisions` 按生成任务保存改写调用前的占位与最终决定。恢复会复用成功决定；若调用曾中断，保守返回原查询，不重复改写。请求与版本、文本端点签名不匹配时拒绝复用。生成证据记录开关、版本、原查询、有效改写、降级原因、两路排名、融合分数及耗时；不归档原始错误正文或模型理由自由文本。

## 验证及证据边界

本轮使用隔离 HTTP 模型与临时账号验证开关实际进入检索：浏览器中开启融合、回答追问并生成后，任务成功，保存的 `query_fusion=true`，检索证据为 `applied`。这是 mock 流程验证，没有新增真实模型调用或召回率测量。

浏览器目视与交互检查覆盖：英文浅色设置和追问、中文深色窄屏追问、390px 无横向溢出、Escape 保留草稿、页面切换保持融合开启、切换第二账号默认关闭。恢复桌面尺寸和浅色后再次查看生成页，一行追问开关没有附属小字。

最终相关后端回归为 256 项通过（包含 30 项融合测试），全部前端测试为 88 项通过。后端套件覆盖融合、检索集成、R4 运行时、生成准备、Agent 恢复与生成、账号隔离、追问和原工作流。测试覆盖旧默认兼容、HTTP 请求绑定与账号边界、不可变快照、重试、单次改写恢复、歧义/未知回退、第二路失败、候选上限与排序语义。范围与前一轮 262 项后端套件不同，不能把数量变化解读为测试删减或质量变化。

RRF60 选为默认关闭的工程候选，来自 [R8A 融合消融](R8A_FUSION_RESULTS_20260920.md)的参考；本次使用新的保守运行时提示，不能直接继承 R8A 的指标。R8A 复用了已经曝光的 R7 数据，未证明全局最优。[R8B](R8B_RESULTS_20260920.md)的信息不足与语义风险仍成立。下一轮效果研究需要冻结独立输入，分别统计开关开/关的召回、语义保留、失败、延迟和调用成本。
