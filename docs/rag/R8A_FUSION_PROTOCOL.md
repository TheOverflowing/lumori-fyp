# R8A：固定改写文本的首阶段融合消融

日期：2026-09-20。性质：**离线、探索性后续实验**，不更改生产配置。R7 的结果已知，因此即便保留其 dev/test 划分，也不能把 R8A 的 test 称作新独立测试，或从本轮中挑选上线冠军。

## 问题与冻结

保持 R7 的资料、切片、原问句、normalize 改写文本、查询向量和文档向量完全相同，只改变检索融合机制。运行程序必须先记录 R7 目录所有现存文件的 SHA256，以及本协议、脚本、检索实现和评分依赖的 SHA256，落盘 freeze.json 后才计算新排序。原 R7 目录只读；结束时重新检查所有原始文件哈希。套接字连接和 Provider 构造均被本地禁止，不产生新 API 请求。

## 固定条件

- R7 源目录：`docs/rag/r7-experiments/20260919T161914951306Z`。
- 219 份文档 / 380 个切片；256-token 递归、标题路径编码、metadata weight 0。保持原文件顺序和同分时的语料顺序。
- 120 条双语输入。L0–L3 共 96 条进行质量评价，保留 dev 32 / test 64；L4 的 24 条歧义输入单列排除，不对隐藏原始意图评分。
- 主实验只采用生产同类的 `hybrid_dense_lexical_v1`：余弦分数加归一化 BM25 奖励（上限 0.05）。每个内部 dense / lexical 路径最多各取 20，合并后每个检索结果最多 20。两查询融合最多读取 40 个去重候选，最终仍最多 20。这个预算是输出候选预算，不意味着相同计算量。
- 原文、normalize、dual 首先重算并逐项验证与 R7 原始候选和首阶段指标一致，失败即停止。
- 沿用 normalize 的澄清或机械校验回退决定；不得因质量低而跳过输入。L0–L3 若触发澄清，各改写依赖臂记零；机械失败统一回退原文。

## 七个实验臂

| 臂 | 固定行为 |
|---|---|
| original | 原文向量 + 原文词汇检索 |
| normalize | R7 normalize 向量 + normalize 词汇检索 |
| interleave | 原文和 normalize 的两个 Top20，原文优先交替去重至 20；等同 R7 dual |
| rrf60 | 同样两份 Top20，按 `sum(1 / (60 + rank))` 融合；rank 从 1 开始，缺席路径贡献 0；同分按语料顺序 |
| vector_a015 | `unit(0.85 * unit(q_original) + 0.15 * unit(q_normalize))`；词汇检索固定用原文 |
| vector_a030 | 改写向量权重 0.30；其余同上 |
| vector_a050 | 改写向量权重 0.50；其余同上 |

向量融合的 alpha 表示 **改写权重**。先各自归一化再加权，最后再次归一化。原文词汇路径保持不变，因此该组直接研究语义向量插值；alpha=1 的语义部分等于 normalize，但词汇部分仍不同，不能称作完整 normalize 端点。本轮不额外搜索权重，不更换提示词，也不声称复现某篇论文的全部算法。

## 指标与报告

仅报告首阶段已知证据 span Hit@1、Hit@5、Hit@20、MRR@20；计算定义保持 R7。展示 dev/test 分别的总体、L0–L3、中文/英文，并给出相对 original 的逐题改善、持平、受损数。报告同一信息需求的多种表述，不能当作独立学生样本。

所有结果为固定候选策略的探索性描述；不进行新的统计显著性宣称，不按 test 选择生产策略。复用 R7 的 AI 辅助标签和两本教材局部主题，不能表述为教师金标、真实学生或未见教材泛化。

不调用重排，不把旧 R7 共享重排分数套到新候选，不报告新的最终上下文命中率或回答质量。新增 API 次数与费用为 0；既有向量/改写的历史费用是沉没实验成本，并非在线部署免费。不同臂的本地运行时间只作日志，不用于在线延迟比较。

## 复现与校验

从仓库根目录使用 `.venv/bin/python scripts/r8_fusion.py`；可用 `--output` 指定全新的输出目录（必须位于 `docs/rag/r8a-experiments/` 内）。已有输出不覆盖。脚本归档自身和协议，保存冻结清单、候选、逐题指标、汇总 CSV、逐题变化 CSV、R7 排名一致性检查、原始文件未变检查、运行环境和结果说明。

测试覆盖向量融合端点/比例/非法向量，RRF 排名与去重预算，R7 候选和指标一致性、冻结文件改动检测，以及网络禁止规则。
