# R8B：必要时追问的受控检索试验 v1

日期：2026-09-20。在任何本轮模型调用之前冻结数据、四个角色提示、代码与模型标识。只测首阶段检索和交互，不生成最终答案、不调用重排、不改生产配置。预注册比较而非上线选择。

## 研究问题与数据

新建8个计算机课程信息需求，每个中英两种语言、formal/colloquial两种表达、sufficient/underspecified两种信息充分性，共64条。课程源文档复用R7固定教材，信息需求新建，属于已见教材上的新问题，并非未见领域。题目、证据、隐藏用户意图均为AI辅助暂定资料；没有真人学习者或教师金标。

按支持文档合并family，每个分量的代表component为其中按字典序最小的family_id（不是展示用的component-ID）。依SHA256('r8b-split:'+component)排序，前max(1,floor(n/3))分量dev，其余test。全部语言/风格/充分性跟随family。提示和规则对两部分相同；本轮不根据dev再改提示或阈值。test结果单独报告；小分量bootstrap仅探索性。

明确输入用固定证据span测Hit@1/5/20及MRR@20。模糊输入对应预先声明的模拟用户意图；使用同一证据测的是 **target-conditioned evidence alignment（给定该用户意图的证据匹配）**，不把未澄清前其他合理解释宣称为错误。两类指标分开，不能合并称整体正确率。

## 三臂及信息边界

1. original：原文直接检索。
2. normalize：带意图保持约束的术语归一化，不允许提问；信息不足则尽量保留原文，禁止猜测、补答案、强化范围。
3. selective：query-only策略，选择keep、rewrite或clarify。仅缺少区分不同实质需求的条件时提出一个问题；不知道答案不是提问理由。

前三个决策输入只有用户实际文本、语言及统一CS领域说明。不发送family、风格/充分性标签、标准问句、隐藏意图、教材、证据、检索分数或另一语言版本。

仅selective提出问题后启用模拟用户。模拟用户看到原问题、实际追问和预先冻结的意图profile，不看到答案或证据。profile只能包含用户知道的对象、任务、条件，不能含正被询问的定义、复杂度、公式等答案。回答只回应追问；无信息时返回unknown，禁止为了完成任务猜测或直接倾倒整个profile。非unknown需提供profile原文support_quotes；程序验证引用确实存在，但引用存在不等于推理蕴含，另做AI语义审阅。

最后的resolver只看原问题和实际问答，允许decline为unresolved，不再问第二轮。unknown、无效响应、未解决及接口失败保留原文回退，并在分母中保留；回退不算澄清成功。有效回复后也不把新增答案当作资料证据。单轮追问的最大交互预算为1。

实现直接将unknown回复标记未解决并回退，不再花一次resolver调用；文本角色失败同样回退。若查询嵌入本身失败则候选为空、质量记零，不补造向量。数字含正负号进行字面保护，但比较关系、术语和其他语义仍需另行审核。

## 固定检索与报告

deepseek-flash：temperature0、thinking disabled、各角色最多512输出token。qwen/qwen3-embedding-8b：固定CS查询前缀、4096维，查询去重后每批16。复用R7已核验的380课程/干扰片段向量，256token递归无重叠、标题路径；hybrid_dense_lexical_v1、metadata0、每臂20候选。不要把批量嵌入耗时当成在线单用户延迟。

本轮不重排。追问后的查询包含新增意图信息，共享一次重排会使基线看到不属于其输入的信息或压制追问收益，因此只报告首阶段。Hit采用片段联合覆盖至少一个完整已知span；MRR要求单片段完整覆盖。

主要报告test中信息完整输入的Hit@5/误追问比例，以及模糊输入的target-conditioned Hit@5/主动追问率。MRR@20、Hit@1/20、未知回复、未解决、格式失败、回退、查询语言、表达风格、逐题改善/损害为辅助指标。语义审阅独立标记答案提示、无根据猜测、范围改动、回复是否超出profile或答非所问。不因审阅删题、改主分母或更换策略；未解决的仍按实际回退结果评分。

同时列问法可回答率与回复有效率，明确其条件分母，并保留全部输入的主指标。对充分输入的误追问即使最终检索正确也计为交互代价。original/normalize无澄清检测，不给其伪造分类准确率。全部成对比较按文档分量聚类bootstrap，2000次、seed20260920，置信区间不作普遍有效性证明。

不根据作者人工style/clarity标签路由。任何后续产品路由只能使用运行时真实可用信息。本轮没有人为挑选最有利追问、手改模型回复或多次生成择优。

## 预算、失败及复现

最多256条逻辑text调用（64normalize+64selective+最多64reply+64resolve）、512text HTTP attempts。最多192个独特查询输入、12逻辑嵌入批次、24embedding HTTP attempts；rerank0。并发text2、embedding4，60秒超时。仅429/502/503/504可预定重试1次，其他失败/超时不重试。复用R7账本实现；另冻结R8B能力上限覆盖，并保存每次实际请求状态、消耗、错误。

OpenRouter沿用4美元已报告金额请求前护栏和每在途请求0.02预留；不是账户硬账单上限。成功响应缺计费数据停止，历史缺失不得重启绕过。DeepSeek未报告金额时保留tokens、不记零费用。最终只使用实际返回模型名称；本轮不调整用户模型配置。

保留完整非敏感输入、原始可见输出、角色投影、请求签名、向量、候选、指标、环境和审阅。不日志化凭据。冻结R7来源哈希，运行结束复核未改动源档案。提供禁止网络的本地重放，重放不构成新模型质量实验。

## 预定结论边界

追问有效只说明该模拟用户profile与这批课程输入下的潜力。模型模拟用户、AI证据、规模小、已有教材、缺少真实用户交互与生成质量验证，都限制结论。单纯命中提高不能抵消意图偏移；效果不明显或误追问多时保留负结果。与R8A独立报告，不把融合和追问的收益相加。
