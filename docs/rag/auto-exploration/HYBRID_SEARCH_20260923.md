# 自动探索混合搜索：从有限目录扩展到跨学科候选

日期：2026-09-23。目标是让开启自动探索的学生，在主题不在预置目录时仍能发现公开资料，同时保留已有许可、正文、向量检索和证据门禁。旧的 `curated` 与需独立密钥的 `brave` 保留；新任务默认 `hybrid`。

## 流程

1. 模型先检查课程资料缺口，产生不含密钥/私人地址等敏感文本的中英文查询。
2. 每条查询先匹配本地已核验课程目录，并预留至多两席通过 [Wikimedia Action API](https://www.mediawiki.org/wiki/API:Search) 搜索同语言维基百科正文命名空间。只接收有页面 ID 的文章标题，排除消歧义页；URL 由固定域名和标题构造，不信任 API 返回的任意 URL。请求不跟随重定向，单次响应上限 1 MiB，按 [Wikimedia User-Agent 规范](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy)标识项目。
3. 搜索摘要只提示候选。实际网页继续由现有的公共地址校验和 DNS 固定下载器读取；未知页面必须从发布者页面确认许可。实测维基百科正文页面声明 CC BY-SA 4.0；没有声明或只有链接许可的页面不能自动入库。百科文章可能包含例外素材，本流程只解析文本，不将图片作为已理解证据。[Wikimedia 的许可说明](https://foundation.wikimedia.org/wiki/Terms_of_Use)。
4. 长文章若超出切分预算，按已冻结的缺失知识点保留相关**原文片段**，记录 `web_relevance_excerpt_v1` 警告和原始下载文件哈希；其余内容不被当成已检索证据。随后建立候选向量索引、召回段落、做逐项证据筛选，全部通过后才保存到当前课程。

如果百科搜索暂时不可用而目录有候选，仍可使用目录结果；两者都不可用时返回明确的搜索失败。此策略比目录广，但百科不是所有学科的正式课程教材，也不是全网搜索；需要更广来源时已有 `brave` 适配器，必须由维护者提供单独密钥。

## 隔离验证

真实搜索接口查询 `quantum entanglement` 得到两篇文章候选；中文 `洛必达法则` 同时得到精选教材和中文百科候选。一个目录外的本科物理单题请求在临时 SQLite 中完成真实的模型查询、网页下载、嵌入和召回：英文与中文查询各有 2 个候选，接受 1 篇中文百科文章，最终召回 5 个片段，模型内部判断 `sources_sufficient`，耗时 63.67 秒。原始精简记录见 [`live_isolated_20260923.json`](../../../benchmarks/auto_exploration_hybrid_v1/live_isolated_20260923.json)。临时数据库已销毁，没有生成题目或修改用户课程。

首次运行中，英文维基百科文章因切分片段数过多被拒绝。加入相关原文片段截取后，再用同一网页做只读验证：原始下载约 1.04 MB，索引文本 22,020 字符，按实际 tokenizer 切成 25 个片段，保留 CC BY-SA 4.0 页面许可及截取警告。这一项验证了索引容量，没有重新进行完整模型筛选，因此不能把它写成英文文章已成功入库。

自动探索、来源发现、探索上下文与生成准备相关离线测试共 260 项通过。上述 `sources_sufficient` 是系统内部模型判断；没有教师复核、题目正确性或学生学习效果测量。中文维基百科文章本身的事实质量也不能由许可与召回成功推断。
