# 自动探索首次真实试跑记录 · 2026-09-20

本次完成了真实公开网页读取、模型调用、资料入库与学习讲解生成的开发试跑。第一轮从无资料开始，生成流程成功，但输出中文偏离英文请求；加强生成语言约束后，第二轮复用已保存资料，输出英文。两轮均保留原始记录与生成内容，不覆盖第一次的偏差。

## 2. 第一轮：资料发现成功，输出语言不符

初始覆盖检查返回 `missing_knowledge`，识别出栈操作规则和教学示例两项缺口。系统执行两次本地目录搜索，检查英文与中文 Python 官方教程候选。英文页面记录为 `invalid_selection`，中文页面通过筛选并保存到课程库，再建立索引、重新检索和检查。

接纳来源为 [Python 中文教程：数据结构](https://docs.python.org/zh-cn/3/tutorial/datastructures.html)，记录的存储政策为 `open_license`，许可描述为 `Python documentation license (PSF)`。正文支持信息包括列表的后进先出用法、`append()`／`pop()` 的规则及栈示例，保存了页号和字符位置。该引用位置指解析后的网页文字，不是网页视觉布局坐标。

英文候选被拒绝的原因代码只表明它未通过本次选择契约，**不能据此认定英文教程无关、错误或比中文教程质量低**。该拒绝作为真实失败记录保留，没有从候选处理中删除。

补充后，覆盖判断为 `sufficient`，探索结果为 `sources_sufficient`，作业状态为 `succeeded`。但是保存的标题为“用 Python 列表实现栈：append() 与 pop()”，四个小节标题和正文主要为中文；这与请求和生成契约中已经存在的 `language=en` 不一致。因此，本轮只能记为 **资料发现、索引与生成流程贯通，输出语言要求未满足**，不能记为全部用户要求验收通过。

网页解析同时保留 `needs_review` 状态和 `web_visual_or_formula_content_not_interpreted` 警告。正文可用、引文存在或模型判断通过，都不等于页面布局、配图和公式已被完整识别，也不构成人工语义核验。
