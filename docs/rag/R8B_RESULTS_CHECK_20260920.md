- `avl-rotation-case-en-colloquial-underspecified`：rewrite

## 3. 追问路径及模拟回复风险

所有 64 条输入中，selective 的实际有效动作是 keep 53、rewrite 9、clarified 2。两次追问均发生在中文、口语、underspecified 输入上，dev / test 各一次。没有触发 unknown 或 fallback。

共 32 条 underspecified 输入中只追问 2 条，即 6.25%；test 为 1/24，即 4.17%。32 条 sufficient 中追问 0 条。**低追问率不能当作已正确解决其余歧义的证明**，unknown 为零也不能证明模拟用户处理未知信息的能力。

两次 resolve 均返回 `resolved=true`，这是模型报告的状态。直接检查 `reply-support-audit-inputs.json` 与相应 resolve 输入可见：

1. **AVL，test。** 追问只询问哪个节点失衡、左重还是右重；模拟回复额外提供“左孩子平衡因子为 -1”。这个事实确实来自隐藏 profile，但超出了实际追问的区分范围。冻结 reply 提示明确要求只回答被问到的区别、不主动补充其他约束，因此该回复可能掩盖追问本身缺少关键条件的问题，不能把它当作合格的自然用户闭环验证。
2. **图遍历，dev。** profile 说明图已经非连通，任务是访问每个顶点、询问如何继续。追问把选择限制成“是否覆盖起点分量”或“是否判断整个图连通”，模拟回复选择后者；其 support quote 只支持“需要访问全部顶点”，不支持把目标改成判断连通性。resolve 继续把问题改成“如何判断无向图是否连通”，原来的后续遍历操作需求丢失。

这些检查支持“**两次模拟回复均存在方法风险**”，不支持“追问已成功解决两例真实用户歧义”。本复核者已经看过指标，因此这段是透明的事后检查，不能冒充独立盲审或教师审核。专门的语义审核应另行保留其输入可见范围与结论。

## 5. 前次失败运行不可漏计

中止目录的 `calls.json` 有 **128 次文字 HTTP 400**，全部状态 failed、attempt=1。`diagnostic-400.json` 另存 **1 次 HTTP 400 诊断请求**。因此中止运行共 **129 次 HTTP 尝试**，不是 128 次。

诊断错误明确指出，使用 JSON object 响应格式时提示必须出现 json 一词。这是请求契约问题，不能解释为模型检索或追问能力失败。该运行没有嵌入调用、重排调用或实际候选排名文件，不得把有效查询文件里的回退文本当作已完成的质量评估。

两次运行合计：**270 次 HTTP 尝试 = 129 次失败/诊断 + 141 次有效运行尝试**，其中 DeepSeek 文字 261 次、嵌入 9 次。旧运行 129 次没有返回费用或 tokens；有效运行 132 次文字没有返回费用。合计 **261 次金额未知的文字尝试**，不能把它们当作零费用。现有已知金额仅为嵌入的 **0.00006857 美元**，不代表全部账单。

## 7. 可据此写入论文的范围

本轮可以报告一次严格记录了失败、追问频率与负结果的选择性澄清实验：有效请求恢复后，策略仍极少追问；test 的证据指标与原文逐题相同；两次模拟回复均暴露额外约束泄漏或目标偏移风险。

本轮不能证明追问没有价值，也不能证明追问功能已经有效。它指出下一步应修正模拟回复约束检查和澄清路由的评测设计，并在新的输入上验证。现有 AI 标签、已见教材和小规模主题留出，也不足以推广到真实学生或教师工作流。
