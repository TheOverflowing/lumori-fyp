# 自动探索 v1：实现边界与评测协议

记录日期：2026-09-20。适用对象：中英文计算机本科课程的学习讲解、测验与作业。本文记录首次接入的设计、配置与验证口径。[两次真实功能试跑](auto-exploration/SMOKE_RESULTS_20260920.md)已记录：无资料路径贯通并发现语言偏差，修正后复用资料生成英文；正式效果对照尚未完成。后续结果应另建冻结目录，不覆盖本文的初始协议。

后续修订：当前运行策略为 `auto-exploration-v2`，来源目录为 `cs-public-sources-20260920-v3`。新增机器学习来源、弱关键词的领域约束、逐查询审计、先索引后筛选的临时向量检索，以及已核验原文支持片段的上下文保留。初始 v1 试跑文件保持不变；本次问题、失败试跑与修复验证另见[机器学习资料发现记录](auto-exploration/ml-discovery-20260920/README.md)。

## 1. 目标与当前边界

没有上传材料、已有资料与主题无关，或检索结果只覆盖部分必要知识时，系统可以在生成前补充公开参考资料。用户在“设置 → 自动探索”中主动开启；默认关闭，偏好按账号保存在当前浏览器。只有开启该模式，空资料课程才可以提交生成；课程、文本与嵌入模型仍是必要条件。失效索引、错误的指定资料范围和模型配置问题需要修复，不能由联网探索掩盖。

第一版默认提供 `curated`：在本地维护的公开课程网址目录中匹配中英文概念词，再联网读取这些页面。它无需搜索 API 密钥，但不是实时全网搜索，也不会自动发现目录以外的新站点。目录的别名匹配用于寻找候选，不能证明页面实际包含所需知识。

可选的 `brave` 适配器使用 Brave Web Search API 搜索网页，需要维护者配置专用密钥。实时搜索也不等于允许自动保存任意结果：已核验目录来源按照登记政策处理；未知公开网页可在内存中有界读取，检查页面头部或带许可文字的页脚是否声明了受支持的 Creative Commons `rel="license"` 链接。没有认可的明确声明、仅允许链接或仍属未知许可的材料不会自动存入课程库。声明检测不证明发布者拥有全部内容的授权。

开启探索不会取消生成阶段的证据要求。探索未能补齐依据时仍会停止，并显示缺失输入、未找到可用来源、预算用尽或服务不可用等结果。当前没有悄悄切换到纯模型知识作答的兜底模式。

## 2. 从资料缺口到生成依据

1. **检索本地课程资料。** 复用当前切分、向量检索、可选融合和重排配置。没有索引仅在自动探索路径允许作为空检索结果继续。
2. **判断覆盖情况。** 文本模型把请求拆为最多六项必要概念或规则，并区分 `sufficient`、`missing_knowledge` 与 `needs_user_input`。初始规划要求贴合用户请求的范围，简短介绍不应扩成完整课程；一旦确定，后续检查保持这些需求不变。判为已覆盖的条目必须选择真实正文片段 ID，控制器取得对应连续原文。单独的 Markdown 标题不作为说明性证据提供给覆盖模型。已覆盖条目可以省略无用的空查询列表，由控制器补为 `[]`；未覆盖条目仍必须给出有效查询。
3. **构造有界搜索。** 对缺失的一般知识生成中英文概念查询，先过滤明显的 URL、邮箱、密钥形式、长数字和控制字符，再交给已配置的来源适配器。
4. **读取、临时索引与分项召回。** 候选先经过来源、下载类型、大小和保存许可检查，再解析正文。v2 对预算内的完整正文按当前配置切分并嵌入，写入任务私有的临时索引；模型尚未筛选的候选不会出现在课程资料库。将每个缺失知识项及其双语查询分别用于混合检索，每项取前 4 个片段并交替安排；保留这些原始片段后，利用剩余额度补充同页、同小节的后邻块，再补前邻块，合计最多 24 个不同片段。超过单份资料上限时明确拒绝，不静默只索引开头。
5. **核验与保存。** 模型基于召回的正文片段判断是否支持至少一项缺口，并选择片段编号。控制器用编号取得真实原文和页内坐标，不要求模型重新抄写引文。标题、搜索摘要和目录关键词不作为支持结论的原始证据。通过检查的资料连同已有向量一起保存到所属账号的当前课程，无需再次嵌入；保存完成才启用。探索结束或中断时清理临时正文和向量，保留有界审计记录。
6. **再次检索并检查。** 用补充后的课程资料重新组成上下文。v2 同时从候选筛选时已核验的原文引文坐标找回实际索引片段，按知识项交替安排，避免“已经找到资料，宽泛主题检索却丢掉关键子主题”。此补充路径最多 24 个叶片段、4096 个来源正文 token，不改变普通 RAG 的默认 1024 token 配置；其额外预算和实际用量单独记入 `support_context`。仍由模型对最终上下文复查，片段存在不自动算语义覆盖。仍有一般知识缺口且预算允许时进入下一轮；否则停止探索。
7. **固定依据后生成。** 将选中的资料及配置固定到本次任务的证据记录，再进入既有的规划、逐题生成、审核与保存流程。

资料只需要支撑概念、规则和解题方法；新练习的数值与情境可以构造，不要求教材中已有同一道题。另一方面，“根据老师发的那张图出题”“解释这段未提供的代码”等请求缺少的是用户特定输入。系统应返回需要补充的信息，不能用网上另一张图或另一段代码代替。

这里的覆盖与候选选择都是 **AI 辅助判断**。连续引文匹配只能证明这段文字来自已读取的正文，不能证明它蕴含目标结论、没有上下文遗漏或本身真实。最终生成与引用核查仍需独立执行。

## 3. 来源、解析与账号归属

| 环节 | v1 行为与限制 |
| --- | --- |
| 来源目录 | 维护真实公开课程和文档页面的 URL、主题别名、语言、署名、许可链接及存储政策。策略绑定具体已核验页面，不把整个站点视为同一许可。 |
| 搜索 | `curated` 检索本地网址目录；`brave` 调用实时搜索接口。搜索返回只是候选，未经正文筛选不能直接成为生成依据。 |
| 下载 | 读取公开 HTTP(S) 资源；不携带用户登录凭据；对目标地址及重定向重新校验，限制资源大小和下载时间，不执行网页脚本。未知网页的暂存正文只在内存中用于许可检查，许可和证据门槛通过前不正式入库。 |
| 域名解析 | 默认 `auto` 先检查系统返回的地址。仅当遇到 `198.18.0.0/15` 代理映射地址，或 `::ffff:0:0:0/96` 中恰好嵌入这个 IPv4 范围的无 scope 翻译形式时，才请求固定 TLS DNS-over-HTTPS 服务并校验、固定其公网结果；不会连接这些虚拟地址。其他私网、翻译形式和混合私网结果仍拒绝；不修改系统 DNS、代理或网络设置。`system` 关闭该兼容回退。 |
| 网页正文 | 使用可见文字提取，去除脚本、导航等内容。v1 没有浏览器执行 JavaScript 的抓取路径，动态页面可能无法取得足够正文。 |
| PDF | 衔接已有文档后端，使用 Standard 档位。解析是否成功仍取决于文件、服务和时限；不会因为来自可信站点就自动认定识别无误。 |
| 纯文本 | 接受 UTF-8 文本或 Markdown，保留原文作为后续切分的依据。 |
| 配图 | 本次自动探索默认不处理图片，不调用视觉模型。扫描图、公式或图表中未被正确提取的信息不能由标题或猜测补齐。 |
| 存储政策 | 允许目录中已核验的开放许可来源及具有受支持明确声明的公开网页入库，同时保留署名、许可及出处。前者标为 `catalog_reviewed`，后者标为 `publisher_declared`。目录策略只绑定已核验页面；页面声明只适用于对应页面，不扩展到整个站点或重定向目标。仅链接和许可未知的材料不自动保存；公开可读不等于许可无限复制。 |
| 归属与生命周期 | 按当前账号、当前课程保存。新增资料标记“自动发现”，用户可查看原始来源、停用或删除。相同内容不重复创建可用副本，也不擅自恢复用户已停用或删除的资料。 |
| 可追溯性 | 记录原始及最终网址、标题、获取时间、内容散列、搜索提供方、存储政策与许可；任务记录保留缺口、候选处理与原文支持信息。 |

v2 的向量数据沿用 SQLite 持久化及应用内混合排名实现，不要求额外部署独立向量数据库。候选放在按任务隔离的 `exploration_candidate_indexes` 中，当前课程检索不会查询这张表。只有完成筛选后，已有向量才转入正式文档与片段表；正式索引保持现有账号和课程隔离。正常结束、异常、取消和启动时确认中断的任务会清理临时全文及向量载荷，保留配置和审计；未完成的调用不自动重放。

搜索服务的输入限于生成出的公共概念词，不直接发送上传文档全文、账号信息或整个用户请求。覆盖检查会像既有 RAG 生成流程一样，把必要的课程片段发送给配置的文本模型。查询内容约束和模式过滤属于当前防护措施，并不是已经证明不会泄露任何语义信息的形式化保证；正式实验应检查实际发出的查询。

用户关闭自动探索只影响后续新请求。已经接纳到课程库的资料仍由该账号管理，既有生成内容保留当时的历史依据。

## 4. 配置、预算与中断

维护者在本地 `.env` 设置来源提供方和上限，重启后生效。前端只显示来源服务及是否可用，不显示密钥；`available` 表示配置满足启用条件，不代表已验证每个外部页面都能访问。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `EXPLORATION_ENABLED` | `true` | 服务端是否允许此功能；用户开关仍默认关闭。 |
| `EXPLORATION_SEARCH_PROVIDER` | `curated` | `curated` 或 `brave`。 |
| `EXPLORATION_SEARCH_API_KEY` | 空 | 仅 Brave 搜索需要；与文本和嵌入服务密钥分别配置。 |
| `EXPLORATION_DNS_MODE` | `auto` | `auto` 仅对指定代理映射地址启用固定 DoH 回退；`system` 只采用系统域名解析并拒绝非公网结果。 |
| `EXPLORATION_MAX_ROUNDS` | `2` | 最多两轮搜索与补充后的复查。 |
| `EXPLORATION_MAX_DOCUMENTS` | `5` | 每个探索任务最多接纳五份资料。 |
| `EXPLORATION_MAX_SEARCH_CALLS` | `8` | 整个探索任务的搜索调用上限。 |
| `EXPLORATION_MAX_CANDIDATES` | `12` | 整个任务最多处理的去重候选数量。 |
| `EXPLORATION_MAX_SOURCE_PAGES` | `20` | 单份探索资料页数上限；超过时选择更聚焦的章节，不自动截断成完整资料。 |
| `EXPLORATION_MAX_SOURCE_CHUNKS` | `100` | 单份探索资料切分后的片段上限；同时受通用文档上限约束。机器学习问题排查发现正常教材章节需要 94 个片段，故从初始 64 调整到 100，仍不静默截断正文。 |
| `EXPLORATION_MAX_MODEL_CALLS` | `10` | 探索阶段的文本覆盖检查与候选筛选调用上限。 |
| `EXPLORATION_MAX_SECONDS` | `180` | 探索阶段时间预算，单位为秒。 |
| `EXPLORATION_MAX_BYTES` | `10485760` | 单份资料下载上限，10 MiB。 |
| `EXPLORATION_FETCH_TIMEOUT` | `20` | 单次下载时间上限，单位为秒。 |

这些是初始工程预算，不是实验确定的最优参数。搜索、解析、嵌入、后续出题调用的计费方式不同；十次探索文本调用上限不等于十次总外部请求，也不是货币费用上限。本地目录查询也作为搜索操作计入任务调用账本与次数限制，但它本身不发出外部搜索请求。探索还可能触发已有检索流程的融合、重排及嵌入调用，需分别计入真实运行的账本。

v2 在筛选引用已涉及所有当前缺口时，先进入最终覆盖检查，不继续下载本轮其他候选。零搜索结果与候选读取/筛选失败分别记录为 `no_search_results` 和 `no_usable_sources`；目录无匹配时说明来源范围有限，不把它描述成全网无相关内容。每次搜索保存有界的查询、语言、提供方、候选网址/标题与数量，下载错误保存固定原因代码。

探索记录在可能产生外部费用的操作前写入进行中状态。尚未完成且中断的探索不会在恢复时盲目重复搜索、模型、解析或嵌入调用；应新建任务，复用已成功入库的资料。完成的探索可复用固定结果，但仍检查所属课程、资料生命周期、内容及配置身份。配置变化或固定资料失效时拒绝混用旧检查点。

进度页展示服务端实际记录的探索、检索、规划、生成与检查、保存步骤。探索细分为资料覆盖检查、搜索、读取、筛选及索引；可展示轮次、查询数和接纳资料数。界面不展示模型内部思维链，也不把动画映射为虚构的完成百分比。阶段时间沿用已有真实计时协议。

## 6. 拟开展的真实课程对照实验

### 6.1 问题与分组

研究问题：在固定资源预算下，按知识缺口收集正文证据，能否比仅用本地资料或直接采用搜索结果提高所需知识覆盖与生成引用支持，同时控制错误接受、无效搜索和成本？

使用中英文计算机本科课程的真实公开资料，课程范围覆盖数据结构与算法、操作系统、数据库等。每个信息需求建立一个 family，中文、英文及跨语言版本沿用同一意图；同一 family 及共享主要支持来源的条目划入同一数据分组。开发集用于确定阈值、目录和预算；保留集在策略锁定后一次性运行并完整报告。

| 情况 | 应单独观察的行为 |
| --- | --- |
| 本地没有资料 | 是否能找到实际支持主题的公开材料；在来源池没有答案时能否停止。 |
| 本地资料只覆盖一部分 | 是否保留有效本地依据并补齐特定缺口。 |
| 本地有无关或容易混淆的资料 | 是否错误地把术语相似当作证据充分。 |
| 本地资料已经充分 | 是否避免不必要的外部下载与搜索。 |
| 缺少特定题目、图片或教师要求 | 是否请求用户补充，避免替换成其他公开材料。 |
| 候选相互矛盾、解析失败或被撤下 | 是否保留失败记录，合理停止并避免有依据的假象。 |

### 6.2 比较策略与预算

| 策略 | 固定处理规则 |
| --- | --- |
| A：现有本地 RAG | 只使用任务初始课程快照及既有检索与生成规则。 |
| B：直接网页补充 | 用原始主题的公共概念查询取得候选，按照搜索顺序接纳通过共同下载与许可限制的正文；不进行缺口级模型选择。 |
| C：缺口驱动探索 | 使用本次覆盖检查、双语缺口查询、原文支持筛选、有限补检索和最终覆盖检查。 |

B 与 C 使用相同搜索提供方、许可策略、候选/文档/时间总预算、切分与嵌入模型、后续重排和生成审核；保留各自额外调用，不人为减去候选筛选的成本。A 无联网费用，作为现有产品基线。`curated` 与 `brave` 必须分别报告，不能把目录检索的结果称为全网搜索效果。B 的查询生成方式及 C 的策略参数应在正式执行前锁定；不得使用标准答案构造搜索词。

正式实验保留两种运行视角：真实联网试验记录当时的可用性、延迟及费用；离线重放使用已保存的合法资料和搜索响应，控制网页变化。实时搜索结果可能因查询策略不同而不同，这属于策略效果；每次实际收到的搜索结果都需归档，重放时按原查询响应恢复。

### 6.3 指标与分母

| 指标 | 口径 |
| --- | --- |
| 必要知识覆盖率 | 最终上下文实际支持的标注知识项数 / 该请求全部必要一般知识项数。涉及缺失私人输入的项不混入一般知识补齐分母。 |
| 完整覆盖率 | 所有必要知识项都被支持的请求数 / 可用公开来源足以回答的请求数。 |
| 接纳资料精度 | 至少支持一个真实缺口的接纳资料数 / 已审核接纳资料总数。没有接纳资料时报告分母为 0，不记作 100%。 |
| 引用支持率 | 引用原文确实支持的可核查主张数 / 带引用的可核查主张总数；同时报告漏引、错引及无来源主张。 |
| 有效生成率 | 完成生成且满足知识覆盖、内容与引用核查要求的请求数 / 可回答请求数。单独列出“生成成功但缺乏支持”的结果。 |
| 不必要停止率 | 在冻结允许来源池中有充分依据、需求明确却未完成的请求数 / 该组可回答请求数。A 因初始库缺失而停止的原因单列。 |
| 应停止却生成 | 需要私人输入、无可用依据或存在未解决关键冲突时仍生成的次数 / 对应不可回答请求数。 |
| 查询与隐私审阅 | 原意改变、待求答案注入、私人内容进入查询等问题的次数与样例；AI 审阅和独立人工确认分别标记。 |
| 资源与时延 | 每请求搜索次数、模型及嵌入调用、输入/输出 tokens、下载字节、各阶段耗时、总墙钟时长、失败尝试和提供方返回的费用。缺失金额保持未知。 |

只有在固定、经过标注的候选或来源池中，才报告明确分母的 Recall@K。未知全网相关页面的总数时，不能把“找到五份资料”描述为“全网召回率达到某个百分比”。按课程、输入语言、来源语言和资料状态分层，保留全部失败请求；比较差异应报告配对区间及实际样本量。

### 6.4 冻结、标注与复现材料

每轮保存独立运行 ID、提交或代码散列、完整配置、来源目录版本、课程初始文件及索引快照、查询文本与搜索返回、候选原文和许可记录、下载与解析结果、引文位置、选择结果、最终上下文、生成结果及调用账本。可公开归档与只能私下复现的资料应分别记录存储政策，不把凭据或账号私有材料写入论文实验包。

必要知识、相关性、原文支持和应追问条件采用明确标注说明。助手可准备候选标签与问题说明，但标记为 AI 辅助暂定；独立人工标注尚未发生时留空，不填写虚构审核人或一致率。正式选择策略前需要盲审抽样及分歧处理记录。自动引用字符串核验不替代语义判断。
