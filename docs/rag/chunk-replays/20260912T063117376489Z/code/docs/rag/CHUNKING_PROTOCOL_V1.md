# R3 切分实验预定协议 v1

冻结日期：2026-09-12，在本轮任何新增嵌入调用或排名之前制定。MLQA 这 92 条查询已在 R2 使用，因此本轮所有结果都是探索性诊断；不能重新命名为未见测试集或据此证明泛化提升。

## 预定实验组

| 组 | 切分 | 最大字符 / 重叠目标 | 排名 | 元数据词法权重 |
|---|---|---|---|---:|
| legacy1200_dense | legacy_char_v1 | 1200 / 120 | dense_v1 | 0 |
| recursive1200_dense | recursive_v1 | 1200 / 120 | dense_v1 | 0 |
| recursive800_dense | recursive_v1 | 800 / 80 | dense_v1 | 0 |
| recursive1200_hybrid | recursive_v1 | 1200 / 120 | hybrid_dense_lexical_v1 | 0 |
| recursive1200_metadata | recursive_v1 | 1200 / 120 | hybrid_dense_lexical_v1 | 0.25 |

前三组隔离切分变化；后两组与 recursive1200_dense 比较属于检索组合探索。metadata 0 与 0.25 是同一切分、同一向量、同一混合规则下的元数据消融。metadata 使用切分器产生的 heading_path/keywords，不能从答案标签添加关键词。所有参数事先固定，不根据本轮 dev 或 test 排名调整。

嵌入输入保持原始正文，不加标题、关键词或查询指令。模型与端点签名必须和 R2 缓存匹配，默认复用 R2 MLQA 的 81 个原段落和 92 个查询向量；只有尚未缓存的新切分文本需要 API。完全相同正文跨组复用同一向量。候选库是全部切分片段，按完整候选数排序；不会预先用答案标签限制候选。

## 原答案跨度如何映射

每条查询从其 family 的英文、中文记录分别取得 `original_context_id` 和 `original_answers`。逐条验证 `answer_start` 与答案长度界定的原文子串确实等于人工答案文本。对切分器返回的原文区间也逐条验证文本等于原文相同位置的子串；源文本哈希必须一致。

只在真实覆盖的原字符区间内计数，不把父段落 qrel 复制给所有子片段。两个语言版本是可替代的已知答案来源；任一已标注答案跨度即可命中。原答案语义与来源是外部人工 QA 标注，新的片段覆盖关系由确定性坐标计算而来，不是新增人工相关性判断。

## 两种固定上下文限制

1. **Top 5**：返回排名前五个完整片段。
2. **6000 个原文字符预算**：从最高排名起按完整片段依次装入；若下一片段会超过预算则停止，不截断、不跳过片段。不把未使用预算计作已返回字符。

这里的字符是 Python Unicode 字符，不是模型 token。重复出现的字符每次占用预算；另按原文坐标合并区间统计去重覆盖。各组可能返回不同数量的片段，这是固定字符预算对照的目的。

每题报告：

- `known_span_hit`：返回片段的区间并集完整覆盖任一已知答案跨度。
- `single_chunk_span_hit`：至少一个返回片段单独完整包含任一已知答案跨度。
- `best_span_coverage`：所有已知语言/答案跨度中，被返回区间覆盖的最高字符比例。
- `known_context_coverage`：有完整答案跨度覆盖的已知来源段落比例（两个语言来源都是已知，不表示必须同时需要）。
- 返回片段数、原文字符总量、唯一原文字符量、重复字符比例和未使用字符预算。

这些是**已知人工答案跨度覆盖指标**，不能称完整教学证据召回率、学习效果或官方 MLQA 答案 F1。按原 split、query language 分组，但两个译文查询是相关 family，样本已见且规模小，不做新的显著性或泛化结论。

## 结构与成本统计

对 MLQA 的 81 个原段落及已下载的 12 个真实教材原文件分别跑三种切分，记录片段数量、长度分布、原文字数、索引正文总字符、去重后的原文覆盖、重复字符开销，以及标题/关键词元数据数量。教材没有人类答案标签，只报告结构统计，不报告召回。教材正文不调用嵌入 API；其预估索引调用数只反映 batch=16 的工作量。

真实新增 API 尝试默认上限 64，批量大小 16。预检先算新唯一文本数与所需调用数，超过上限时不开始。调用使用独立 run/runtime 数据目录；不得写业务课程数据库。

## 保存与重放

默认 CLI 只 preflight；`--live` 明确执行新增嵌入；`--cache` 使用本轮完整缓存离线重放。保存原数据、教材源文本、每组切分、逐题排名/指标、结构统计、正文输入与向量缓存、调用记录、代码/协议/数据哈希、报告及失败状态。R1/R2 历史记录不改动。

每次启动先建独立目录和 started manifest，失败也保留类型、已成功批次和调用记录。离线重放要求数据、正文输入格式、签名、向量维度和向量哈希一致。报告同时展示退步与不变结果；代码或参数变化后另开记录，不能覆盖既有结果。
