# R5：查询翻译与双路召回对照协议

日期：2026-09-12；在任何本轮翻译、查询嵌入、排名之前冻结。仅做隔离实验，本轮不自动更改应用策略。

## 问题、数据与候选

比较查询和资料语言不一致时，翻译查询是否有帮助。保留原文资料，不翻译答案、不向翻译模型提供文档、答案、相邻双语问题或相关性标签。

开发集从已暴露的 R4 88 个双语 family 中按 SHA256(`r5-dev:` + family_id) 排序取前 24 个（48 条查询）。保留集从校验过的官方 MLQA dev/test 包中取预定标题的全部新中英 family，排除任何 R4 family 和任一语言完整原文重合者。名单为 World Wide Web、Google、Google Glass、JavaOne、Microsoft、Microsoft MapPoint、Microsoft Security Essentials、Microsoft Visual Studio、Task Manager (Windows)、Windows NT、DirectX、Pulse-code modulation、Margaret Hamilton (software engineer)。仅依据主题和未使用状态选择，预计 31 个 family / 62 条查询。

这是软件和计算机技术相关 Wikipedia，包含产品与人物知识，不是计算机本科课程金标。保留 156 篇 R4 原文作为共同干扰库，再加入新原文。每个问题测 mixed（全部中英资料）和 cross（只保留另一语言资料）。跨语言方向分别报告 en→zh、zh→en。gold 继承原人工答案跨度，cross gold 也限制到另一语言。

三组都使用相同的 256-token 无重叠切分、标题表示、英文任务指令、Qwen3-Embedding-8B、有界词法加分（最多 .05）、最终 Top20 重排池、Qwen3-Reranker-8B、Top5 种子和 1024-Qwen-token 原文预算：

- original：只用原查询召回。
- translated：只用相反语言的译文召回；重排仍使用原问题，隔离召回查询变化。
- dual：原文和译文各召回 Top20，以原文先行的交替轮询、去重补齐方式选总共至多 20 个候选。相同片段 ID 只占一个位置，不比较两个查询的原始分数。再按原问题重排。

双路多做一次首阶段检索，但不允许给重排器 40 个候选。所有编码、翻译模板、融合、选择和失败规则都在代码中冻结。

## 翻译与调用

使用当前配置的 `deepseek-flash`，temperature=0、thinking disabled、JSON 输出、最多 192 个输出 token；保留数字、缩写、代码标识及实体，不回答问题、不补全指代、不添加上下文。英文→中文可保留原英文技术名称；中文→英文可保留原始标识。只发送单条原问题及目标语言。

检查 JSON、非空、目标语言的基本字符、长度和原问题中的数字/明确代码标识保留。这些是机械检查，不是语义质量认证。保存原始可见译文、检查结果和公开平行人工问题作参考，人工评审列保持未确认；助手复核必须另外标明身份。

最多 110 次翻译、260 次嵌入、660 次重排；翻译/重排并发 2、嵌入并发 4，单请求超时 60 秒，无自动重试。OpenRouter 已报告费用达到 2 USD 前停止新增请求，并为在途请求各预留 .01 USD。DeepSeek 没有费用字段时只报告实际 token 和请求数，绝不估算为零或声称已核对总账单。翻译输出有上述逐请求 token 硬上限。

文档向量可按完全相同输入 SHA、模型/接口身份复用 R4 缓存；本轮原查询与译文向量均重新真实调用，以记录各自网络时间。只在本轮内按完整请求去重重排，缓存键包括模型、原问题、按顺序排列的全部候选正文。相同请求共享成功或失败结果，减少重复计费和不必要的接口噪声；绝不从 R4 复用旧重排成绩。

失败进入主分母：original 嵌入或重排失败为空证据；translated 翻译、译文嵌入或重排失败为空证据；dual 在翻译或译文嵌入失败时显式退回原查询，在原查询嵌入失败时可用译文；没有可用分支或重排失败则为空证据。保存故障及回退字段，不能仅报告成功子集。重排任务按固定 SHA 顺序调度，避免按策略连续运行。

## 统计与解释

先完成 dev，再保存选择锁，才首次处理 test 排名。dev 在全部等权场景上优先 budget 完整答案跨度 Hit，再 MRR@5，完全持平优先 original。test 对三组全部报告，但不重新选冠军。验证门槛：锁定候选总 Hit 不下降，en→zh 和 zh→en 的 cross Hit 不下降，并且总 Hit 严格改善或 MRR 提高至少 .01；只是工程门槛，不代表统计显著性。无论是否通过，本轮结论先作为后续课程验证依据，不自动启用翻译。

报告预算 Hit、Top5 Hit、MRR@5、重排前 Candidate Hit@20、上下文 token、逐题增损，以及翻译失败、保留字丢失、回退、重排失败。答案跨度指标不等于全部相关片段的 Recall。

同一原文可能对应多个 family；将共享任一答案原文的 family 连成组件，以组件为独立抽样单位做配对 bootstrap 2000 次、种子 20260912。两个语言和两个模式不当作独立样本。区间探索性且不做多重比较校正。

分别记录实际翻译、嵌入、首阶段排名、重排网络耗时与实验各阶段墙钟时间。额外提供分阶段相加的查询延迟估计：original=原查询嵌入+排名+重排；translated=翻译+译文嵌入+排名+重排；dual=max(原查询嵌入,翻译+译文嵌入)+两路排名+合并+重排。分阶段实验并非一次真实端到端在线压测，不能将该估计声称为生产 p95。

冻结原文、gold、全部提示与响应、代码、模型身份、向量、候选、原文上下文、计时、失败和调用费用。保存归档代码离线重放，质量指标/排名相同，仅本地重测时间可不同。现有业务数据库、服务配置和历史实验保持原样。
