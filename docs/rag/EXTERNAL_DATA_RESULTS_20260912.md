## 本次改动

在 R1 失败机制基础上新增 `hybrid_dense_lexical_v1`：取两路前 20 并集，以 `cosine + 0.05 × 归一化 BM25` 排序，词法最多加 0.05。候选之间大于 0.05 的语义分差不会因词法信号颠倒。常数在新数据首次排名前固定，没有根据本轮测试结果搜索更好参数。

旧四种策略、嵌入模型、原文输入与其余参数保持原有公式，所有方法复用同一份真实 4096 维向量。未引入查询翻译或改写，不做文字生成，也不调整生产默认值。详见 [首次排名前协议](EXTERNAL_DATA_PROTOCOL_V1.md)。

## test 比较：已知正例 Recall@5

| 策略 | MLQA 中英 CS（80 查询） | T2 中文技术（10 查询） |
| --- | ---: | ---: |
| 原向量 dense_v1 | 91.25% | 40.58% |
| BM25 | 47.50% | 37.31% |
| 等权 RRF | 61.25% | **47.02%** |
| RRF＋MMR | 50.00% | 28.29% |
| 有上限的词法加分 | **91.88%** | 44.74% |

新方法相对 dense：MLQA 增加 **0.625 个百分点**，80 查询中 4 改善、73 持平、3 退步；按 40 个双语 family 汇总为 4 改善、33 持平、3 退步。T2 增加 **4.17 个百分点**，10 查询中 2 改善、8 持平、0 退步。候选在两组上都高于 dense 的均值，但 T2 的 RRF 更高，不能声称新方法处处最佳。

MLQA 的新方法相对 RRF 恢复 30.625 个百分点，但主要比较仍应是相对更强的 dense，而不能只用较弱基线展示大幅改善。两套数据的 Recall 分母和任务不同，不比较它们的绝对高低，也不把 R1 与 R2 的原始读数之差当作算法收益。

## 其他指标与取舍

| 指标：dense → 新方法 | MLQA test | T2 test |
| --- | ---: | ---: |
| Hit@5 | 96.25% → 100.00% | 100.00% → 100.00% |
| nDCG@5 | 87.37% → 89.07% | 64.88% → 67.56% |
| MRR@5 | 88.58% → 93.90% | 73.33% → **71.67%** |

T2 中新方法的 Recall 上升，但首个相关结果的平均位置指标下降，说明需要同时检查排序和覆盖。dev 上新方法 Recall@5 分别为 MLQA 79.17%（dense 70.83%）和 T2 46.46%（dense 43.76%），没有只报告改善较大的划分。

既有 query-level 配对 bootstrap 的新方法差值区间分别为 MLQA [−2.5, 3.75]、T2 [0, 11.67] 个百分点；样本小，且 MLQA 翻译问题共享 family，这些读数不能用于宣称统计显著或泛化提升。本轮只确认了可复现的观察，不证明学生学习效果。公开数据是否已进入嵌入模型训练未知。

MLQA 每题两种语言的答案来源属于一个可替代组；T2 的全部已知正例也放在一个可替代组。因此两组的 `all_evidence@k` 都只等价于 Hit@k，不能解释为多跳答案的必要证据已经找齐。跨问题的未判断片段也不能冒称人工确认的负例。MLQA 混合语料允许同语言命中，并非强制跨语言检索。

## 课程人工标注的下一步

[标注包](../../benchmarks/rag/course_sources/ANNOTATION_GUIDE.md)包括 80 个带原文行号的片段、问题表、相关性评分表与规则。真人填写、复核后，`scripts/build_course_benchmark.py` 会核验来源、文本、标签覆盖、必要证据组与划分，再生成现有评测器可直接使用的版本。当前空表会拒绝转换，不会输出假的 `human_reviewed`。元数据齐全也不能替代真实标注者参与，本次没有伪造标注者身份。

后续应在课程专属标签上比较同语言与跨语言、单证据与多证据需求，再决定是否采用不同融合策略。当前保持 dense_v1 为应用默认，本轮新方法作为可配置实验候选保留。所有已看过的 test 在后续调参中都属于已暴露数据；新的确认性结论需独立保留集。
