# 文档解析源文档隔离确认集

本集服务于 P4 选型确认；不是官方完整 OmniDocBench 评测，也不是代表所有计算机本科课程的测试集。

- 12 个不同源文档组，与 P1/P3 开发集不重叠，组内也不重复；分组证据见 split-verification.json。
- 英文/简体中文各4页CER可评分文本、2页复杂材料。清单的prose层按标注类别筛选，包含三栏索引等文本页，不保证全部是连续叙述正文。CER在8个文本源页上计算；每页原始PDF、同页扫描PDF、模拟退化图片三种配对条件，共36次解析/完整策略。
- 源文档、已有人工校验标注、上游修订、文件哈希和使用条件保存在manifest及upstream文件；这不是本项目新做的人工标注，也不能证明这些公开材料未进入模型训练。
- 样本按固定SHA256排序和既定资格条件选出，在任何候选确认预测之前固定。选择依据、原始入围规则见selection-before-download.json；P4中另有在确认预测前固定的几何候选追加方案。
- 12个生成扫描PDF均为一页、无文字层、仅含一张图片，解码RGB与发布的原图逐像素一致。visual-verification.json保存程序检查，contact-sheet.png及visual-qa保存渲染核对。目视检查由助手完成，不冒充人类新标注。
- 模拟退化使用固定缩放、旋转和JPEG压缩，不等于真实手机拍摄。
- 本集没有figure类别金标准，不能用于确认配图召回能力；原有开发集的配图结果应单独报告。复杂页的其他结构标注保留，不能从“有复杂页”推导“覆盖所有复杂元素”。

预测前只允许数据有效性/渲染核对，不根据模型分数换样。全部成功、空白与失败预测均保留。源文件遵循上游科研使用条款，不把代码许可证外推为文档内容再分发许可。

结果后定性核对发现的p04阅读顺序与疑似参考字形噪声记录在 [P4个案说明](../../experiments/P4-candidate-expansion-20260918/confirmation/case-notes.md)。未修改标注、参考、分层身份或清单哈希。源文档隔离按清单中的上游源文件标识核对，不等同于已完成跨书刊重印/近重复内容检测。
