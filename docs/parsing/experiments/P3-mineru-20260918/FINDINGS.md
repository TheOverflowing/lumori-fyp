# P3 结果解释与选型含义

本轮将 MinerU 4.0.2 的 Basic 与 Standard 加入现有固定公开开发样本。数值、逐页输出、语言分层、耗时、配图指标与审计见 [完整报告](report.md)；环境、下载与沙箱故障见 [SETUP.md](SETUP.md)。

## 1. 之前的选型需要限定比较范围

P1 中的“原生文字 + Tesseract PSM3 回退”是六个已测试轻量候选中的选择。此前没有实际跑 MinerU，不能从 P1 推导“Tesseract 优于所有专业文档解析器”。本轮证明 MinerU 的两档配置能够在这台 16 GiB Apple Silicon 机器上本地运行。Basic 使用 CPU 小模型；Standard 进一步使用本机视觉语言模型，没有调用付费 API。

## 2. 正文平均分改善，仍要保留语言和页面差异

相同 6 个正文源页、每个条件独立统计 Macro CER，越低越好：

| 配置 | 原始 PDF | 同页扫描 PDF | 模拟退化图片 |
|---|---:|---:|---:|
| 当前 adaptive 方案 | 9.81% | 10.60% | 20.70% |
| MinerU Basic | 5.69% | 5.42% | 14.94% |
| MinerU Standard | 4.69% | 4.11% | 9.18% |

Standard 是这三种输入条件下已测候选中**混合正文平均 CER 最低**的配置。这是当前开发样本上的观察，不是所有文件或所有任务的总排名。Basic 的三个英文退化页全部比当前方案差；Standard 的英文退化均值也高于当前方案。中文退化页上的较大改善拉低了混合平均值。

扫描正文达到预设初筛阈值的页数由当前方案 4/6，提高到 Basic 5/6、Standard 6/6；退化图片分别为 2/6、2/6、3/6。阈值为 CER≤10% 且文字长度≥金标准80%。**6/6 达标不等于字符准确率100%，更不等于文档教学事实全部正确。**

原始 PDF 条件也含图像页，并非全是带有效文字层的电子 PDF。两档都使用自动模式；实际选择 `txt/ocr` 的信息保存在每次 `worker.json`。改进不能只归功于某个模型或“加入版面分析”这一单独因素：两档与 P1 同时在区域处理、识别模型和结构输出等方面不同，没有进行单因素因果消融。

## 3. 配图应该同时评估定位、分组和内容

本轮新增冻结的区域定位协议：所有12页均计入，预测 `image/chart` 框与官方 `figure` 框按 IoU≥0.5 做一对一最大匹配。无图页上的误报也进入分母；原始 PDF 和扫描版分别评分。模拟退化图经过旋转，需要额外坐标配准，事先排除该条件的区域分数。

Basic 与 Standard 在原版与扫描版均匹配到8/10个区域；两档区域精确率均为原版57.14%、扫描版61.54%，仍有误报。Standard 的文字均值改善没有进一步提高这一配图定位分数。p04 将金标准合并的上下子图分开提取，单个框与整体框的 IoU 均不足0.5，因此当前协议记为未命中。这里应区分“分组粒度不一致”和“图片真的丢失”；本轮没有在看到答案后合并预测框来提高分数。

此前只导出内嵌位图时，p10 的矢量示意图没有独立图片对象；MinerU Basic 在 p10 原版与扫描版均匹配到5/5个已标注图区域。助手对 p06 的设备/视野配图和 p10 的几何网格裁图做了两例目视核对，内容可见。这证明了区域提取能力的具体改进，仍不是人类语义标注或图意正确率。

表格、公式和图像解释虽有输出，本轮没有计算 TEDS、CDM 或图意准确率。生成看似合理的结构不等于提取正确。后续应核对计算机课程中的树节点、箭头方向、图的边、代码缩进、公式上下标和图表单位，并把这些项目与 OCR 正文分开评价。

## 4. 当前选型结论

MinerU Standard 值得进入下一轮真实课程独立测试，作为高质量结构解析候选；Basic 是本机无需 VLM 的对照候选。当前证据不足以支持所有上传文件无条件切换：样本小、英文退化有反例、复杂结构尚缺专项分数，运行时间也不是公平性能基准。

本轮新增的是独立评测环境、适配与评测脚本、原始结果和记录；没有修改应用默认解析器，也没有重解析用户现有资料。后续接入应保留页码/区域/原图来源、明确解析器版本，并验证现有账号隔离和历史引用；模型生成的图片说明应独立存储，不能冒充原文。

如设计“按页选择轻量或高级解析”的路由，需要先在开发集固定规则，再用独立文档评估。不能利用测试答案在每页选分数更好的引擎，然后把这种答案驱动的选择当作可部署算法。

## 5. 论文中可以和不能写的结论

可以报告：在同一固定公开开发样本、同一文字评分协议下，引入 MinerU Basic/Standard 后观察到上述 CER 和达标页数变化；区域提取补齐了部分矢量图的独立来源；记录了跨语言退化、分组误差与运行代价。

不能报告：已在真实计算机本科课程总体达到上述性能；已经完成真实手机照片测试；所有表格、公式和图意准确；文档解析改善已经证明提高 RAG 召回或出题质量；本方案是所有工具中“最强、最快”。

下一轮应按原文档划分开发/独立测试集，加入中英文计算机课程与实拍照片，固定资源和解析配置，再接同一套 chunk、embedding、召回与 reranker 做下游对照。Docling、PaddleOCR-VL、其他 MinerU 档位等未在本轮测过的候选仍应标为未测，不能根据名称、论文榜单或本轮其他工具的分数替它们下结论。
