# 检索增强生成流程、引用与版本管理的短答案测验

状态：draft

## 检索生成与引用支持

课程材料把生成证据与引用支持作为流程对象。检索为生成器提供检索到的原文片段（retrieved passages），而引用标识通过结构校验并不等于内容由人工审核通过；结构校验只检查标识格式或存在性，不能证明所引段落实际上支持结论。证据边界被越过时（例如课程笔记只讲检索系统，却被要求临床剂量），应报告证据不足，不得编造答案。

## 嵌入兼容性与索引版本

嵌入兼容性关注已存储文档向量与新查询向量之间的关系。向量必须维度相同才能比较坐标，但维度相同不足以说明兼容：两个模型可以输出相同数量的坐标却使用不同的语义空间。因此，用一个模型生成的查询不能被假定与另一个模型嵌入的段落兼容；更换嵌入模型后，旧索引中的向量需要被重建，相关课程材料也可能需要重新审核。

## 审核版本、导出与证据记录

材料区分草案与已批准版本：导出内容应标明当前文本是草案还是已批准。生成证据导出比学生讲义更详细，可包含检索到的段落、配置签名、修订历史和提供方调用用量；同时不得包含凭据。审核记录应保留初始生成草稿、实际检索文本、不含凭据的生成设置及后续修订；人工复核字段应由人填写，自动测试不能冒充人工判断。失败的请求应按状态和安全错误信息保留，证据不足被拒绝与网络错误是不同的结果。

## 难度意图与题目设计

难度意图指题目设计上要求进行的推理。简单题可要求识别一个概念或解释一个直接关系；中等题可在给定情境中应用概念或比较两个相近案例；困难题需综合多个已覆盖概念并分析约束。难度应来自预期推理，不应来自生僻措辞或资料外事实；难度标签不等于实测学生难度，在没有学习者作答数据时不能宣称预测正确率。

## 1. 根据课程资料，检索为生成器提供的是什么？说明该对象与引用支持之间的关系，并指出结构校验不能替代什么。

目标难度：简单



参考答案：检索为生成器提供检索到的原文片段（retrieved passages）。引用支持意味着结论应有资料中的段落支撑，但引用标识通过结构校验只说明标识在格式或存在性上有效，不能证明所引段落实际上支持结论，也不能替代人工审核。

解析：资料要求区分检索提供的方式与引用验证的边界。结构校验不保证内容支持结论，自动草稿不能仅因引用标识通过校验就称为人工批准。

## 2. 某课程系统更换了嵌入模型，但新查询向量与旧索引中存储的文档向量维数相同。请结合课程资料分析：为什么不能直接判定两者兼容？为保证检索流程可用，应处理哪些存储对象？

目标难度：中等



参考答案：因为嵌入兼容性不只是维数相同：两个模型可以输出相同数量的坐标，却使用不同的语义空间，因此旧文档向量与新查询向量不能仅凭维数相同就假定可比较。需要重建旧索引中由旧模型生成的文档向量（即重新嵌入受影响文档），并重新生成或更新与新向量对应的检索索引，使查询与文档来自同一嵌入空间。

解析：资料明确说明匹配维数不足以证明兼容，两个模型可能使用不同语义空间。更换模型后，旧索引向量需要重建，否则查询与文档不在同一空间。

## 3. 情境：某课程有一份已批准的教学文本和一套由旧嵌入模型构建的索引。团队决定更换嵌入模型，并在更换后直接编辑已批准教学文本中的一段定义，随后计划导出学生讲义与生成证据。请依据资料论证：在导出前，哪些存储对象需要重建或更新，哪些审核动作需要重新执行；导出应标明什么；同时说明为什么不能用自动测试结果充当人工审核。

目标难度：困难



参考答案：首先，更换嵌入模型后，旧索引中由旧模型生成的文档向量与新查询向量可能不在同一语义空间，即使维数相同也不能假定兼容，因此需要重建旧索引中的文档向量；如果教学文本被编辑，还应重新生成依赖该文本的索引或向量，使检索内容与当前文本一致。其次，已批准教学文本被编辑后，不能继续默认为已批准状态；应保留初始生成草稿、实际检索文本、不含凭据的生成设置及后续修订，并请人工审核者填写自己的观察与评分，重新确认或批准修改后文本。第三，导出学生讲义与生成证据时，应标明当前文本是草案还是已批准；生成证据可包含检索到的段落、配置签名、修订历史和提供方调用用量，但不得包含凭据。最后，自动测试通过引用结构校验只能说明标识格式有效，不能提供人工质量判断，因此不能把自动测试结果描述为人工批准。

解析：该情境同时涉及嵌入模型变更、已批准文本编辑、导出标注和审核记录。资料说明维数相同不足以证明兼容，模型更换后旧向量需重建；已批准文本编辑后需重新审核；导出应标明草案或已批准；自动测试不能替代人工判断。
