# 文件启用与可恢复删除 — 2026-09-19

课程资料支持“用于生成”开关，以及删除、最近删除和恢复。设计使用系统式绿色滑块、白色圆形滑块头、44px 点击区域；原生 checkbox + role=switch 支持键盘空格和读屏，减少动态效果时关闭位移动画。中英文、深浅色及 390px 窄屏已在隔离测试实例检查。

- 关闭：保留源文件、文本/图片索引和历史引用；在新的检索中排除该文档的文本及图片候选。重新开启直接复用兼容索引。
- 删除：移入“最近删除”，同时停用；这是可恢复删除，不释放源文件或索引占用的磁盘空间，无自动清理期限。
- 恢复：保留索引，默认停用，需手动开启以重新参与生成。
- 已有内容的原文及图片引用仍可由所属账号读取。已经进入模型生成阶段的任务不因切换而追溯撤销；检索末尾会再次过滤在召回期间停用/删除的来源。
- 新的解析、建索引、图片重试和编辑请求不能操作已删除资料。正在执行的解析或图片任务可能完成原有处理，但删除状态独立保留，结果不会因此重新进入检索。
- 再次上传同一已删除文件返回已在最近删除的提示，不自动恢复。
- 新表 document_lifecycle 为增量迁移；缺失记录按启用处理，兼容旧文档。全部读写和恢复操作继续通过账号所有权与 CSRF 验证。

API：PATCH /api/documents/{id} {enabled:boolean}；DELETE /api/documents/{id}；POST /api/documents/{id}/restore。资料列表默认不含已删除项，include_deleted=true 可读取当前账号课程的回收列表。
