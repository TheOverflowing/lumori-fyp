# 自动探索界面核验 · 2026-09-20

本目录截图来自独立临时数据库和 `scripts/exploration_fixture_server.py`，使用虚构资料、账号与模型响应，不写入日常使用数据库，也不调用真实外部服务。浅色界面，1280 × 720。

已沿页面操作验证：无资料且关闭探索时不能生成；设置中开启探索后允许提交；进入详细进度页，显示探索步骤、活动和耗时；完成后点击“查看结果”进入内容详情；来源区域显示自动发现标记及原文链接；切换英文后新增设置、活动和来源标签随界面切换。

- [英文来源区域](sources-en-light.png)：内容正文按原始中文生成请求保留，界面标签为英文；`example.org` 是模拟链接。
