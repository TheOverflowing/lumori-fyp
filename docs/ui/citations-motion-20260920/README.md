## 引用行为

- 方括号、英文圆括号及中文圆括号中的引用均可转换，包括一个括号中多个编号。
- 编号取自当前内容的来源快照，重复引用保持同号；缺失来源明确显示不可用，不伪造来源。
- 未知自动生成编号仅识别 `context_` 加 32 位十六进制字符。普通 `(1)`、`[context_window]`、数组下标和反引号代码保持原样。
- 点击引用打开紧凑卡片，显示标题、页码、原文片段；有网络地址时可打开原文，有关联图片时通过原有鉴权接口展示图片。
- Escape 与关闭按钮返回触发引用；外部点击或焦点离开关闭浮层。键盘开启即时显示。
- 桌面鼠标下引用控件宽 28px、可见数字底板约 24px；触屏指针保留 44px 宽度。浮层按未缩放尺寸计算位置，避免入场动画导致边缘溢出。
- 编辑和导出仍使用原始资产及证据 ID；本次没有重写已保存内容。学习页继续隐藏引用控件，并清理正文中的引用标记。

## 进度行为

- 图层透明度过渡设为 240ms，标题和记录使用 180ms、低幅度的透明度变化；背景保持不动。
- 仅在内容变化时触发过渡，计时刷新不重播。快速更新可从当前透明度继续过渡。
- 完成、失败与连接中断会停止活动动画；完成后仍提供“查看结果”。
- 键盘选择阶段立即响应；系统减少动态效果时停止循环动画，图层改为 100ms 的透明度过渡。
- 详细模式记录区保持高度，移动端步骤导航继续横向滚动。语音、图片、视频沿用相同图层接口，只有实际任务包含对应阶段时才显示。
