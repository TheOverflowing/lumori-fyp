# H7B 英文双题独立内容复核

对象：`docs/agent/flexible-experiments/H7B_20260919/supervisor_v2__humanities_en.json`。任务以 10 次真实模型调用交付 2 道题。本次先阅读最终 `published_content.asset`、冻结来源、两个 brief 和学习者描述，形成内容判断，再查看自动 review 和 attempt 历史。材料为 AI 自编的虚构展览文本；本次是开发过程中的 AI 内容审核，**不是严格盲评、教师金标、真实课程材料评测或学生难度实测**。

核心结论：两题的教学要求均有可观察覆盖，且接受多种有依据的解释；但最终组卷存在来源标签冲突，两份参考答案明显超出自定篇幅，局部推论过于绝对。**不能把自动通过的 11 个 `met` 写成 100% 答案正确率，也不能据此确认 hard 达标。**

## 先看最终成品：组卷后的来源冲突

最终 asset 的公共 `sections` 依次包含：

1. `Source A: the curator's account ...`；
2. `Source B: teaching note ...`；
3. `Sources ...`，内部又将策展人、志愿者、方法说明分别称为 **Source A、Source B、Source C**；
4. `Task conventions`，继续使用第三节的 A/B/C 定义。

q1 要求使用 “Source B for interpretive principles”，q2 则要求分析 “the volunteer's account in Source B”，并使用 Source C 的规则。两套局部编号被合并进同一个公共材料列表，没有题目与局部材料组的明确绑定。学生虽可由语境猜出所指，但**整份题组中的 Source B 不唯一**，不宜直接作为正式练习发放。来源 ID 本身没有冲突，出问题的是面向学生的文本标签。

另外，q1 末尾称 “Source B mentions a volunteer's applause and an unopened letter”。q1 自己公开的第二节方法说明摘录没有这两项，尽管冻结的完整 `fiction_archive_method_en` 有。最终第三节又出现相关内容，进一步增加定位歧义。这是“冻结证据包含”与“实际提供给学生的摘录包含”之间的区别，不能用引用 ID 合法来替代检查。

## q1：策展人的集体声音与遗漏

下表的“完整”指题干与示范答案可观察到所要求的任务和处理，不表示每一句推论都无可改进。

| brief 要求 | 独立覆盖判断 | 实际文本依据与限制 |
|---|---|---|
| r1：明确陈述、志愿者行动、we 的依据 | 完整 | (a) 列出共同开幕、搬箱、儿童驻足、短说明牌和“未完成的历史”，并把 we 对应到开幕与选择说明牌，未把所有人的一致意见当成事实。 |
| r2：具体遗漏及其认知限制 | 完整 | (b) 指出照片选择者、被拒材料及一般观众反应未交代，解释由此不能知道的事项；区分儿童驻足与儿童赞同。 |
| r3：第一人称的局部视角 | 完整 | (c) 将可见的搬箱行动与“志愿者希望档案代表所有人”这一未获支持的意图推断对照。 |
| r4：评价 we 的两种解读 | 完整，推论措辞需收紧 | (d) 分别支持共同参与愿景及内部差异未被交代的阅读，并允许另一解读成立；“would not appear even if present” 的力度超过“现有文本没有呈现差异”，见下文。 |
| r5：不把和谐、排斥、隐秘意图当成已证实事实 | 完整，解释与断言的边界宜更清楚 | (e) 明确说明未证实和谐、审查、排斥或意图；未编造具体拒绝事件。但结尾 “unresolved exclusion go beyond what the text states” 宜限定为“不足以断言排斥已实际发生”，避免被理解成禁止提出带保留的排斥阅读。 |

具体事实均可在策展人来源找到；共同所有权和内部差异属于解释，不是档案事实。未发现确定的外部历史、人物动机或拒收事件编造。

需要收紧的句子是：单一叙述者、没有其他人发言，因此 “disagreement, unequal labour, or contested choices would not appear even if present”。当前文本确实没有说明这些差异，但“只有一个叙述者”不意味着叙述者不能报告分歧；宜写成“这些差异可能没有被报告，因此现有叙述不足以排除它们”。这是论证精度问题，不足以把整项 r4 判成缺失或把假设情形当成已编造的事件。

答案开头明确允许其他合格阅读，explanation 也接受不同的、有文本支持的 we 判断。整体保留了开放答案原则；局部否定措辞不应变成只接受示范立场的评分规则。

## q2：志愿者的掌声、保留的信与归属

| brief 要求 | 独立覆盖判断 | 实际文本依据与限制 |
|---|---|---|
| r1：照片、说明牌、掌声、信的明确陈述 | 完整 | (a) 逐项引用父亲的外套、仅写工厂的说明牌、欣慰、鼓掌、信留在包内及“另一次机会”，没有补写原因。 |
| r2：支持归属与排斥感的不同细节 | 完整 | (b) 用欣慰、鼓掌和未来机会支持继续参与；用未被点名的个人及未公开的信支持未解决的排斥阅读。这是可辩护的解释，不是排斥事件的事实证明。 |
| r3：不能由掌声与信推出审查或信件内容 | 完整 | (c) 明确区分共同出现与因果关系，说明来源未报告拒收、原因或内容。 |
| r4：比较公共叙述与私人犹豫 | 完整，排他措辞需收紧 | (d) 使用双方原文论证两种视角可以共存；但 “Conflict arises only if ... unanimous feeling” 排除了过多其他合理的“叙事张力”解释。 |
| r5：整体解读、竞争解读和边界 | 完整 | (e) 提出暂时归属，给出未解决的排斥作为对手阅读，又明确允许混合阅读，并列出因果、内容与拒绝事件的未知项。 |
| r6：不编造保留信的原因、内容或拒绝 | 完整 | (f) 明确禁止把这些未知项说成事实，并以志愿者来源和方法规则说明限制。 |

“两种叙述可以共存”本身有充分文本依据；问题在于 **only if**。读者可以认为集体公共叙述与私人犹豫存在语气、重点或代表性上的张力，同时不把 together 解读成“所有人心情完全一致”。参考答案宜区分“事实矛盾”与“叙事张力”，避免把后者也排除。此处不影响比较任务已实际完成，但会影响开放题评分的公平性。

未发现信件内容、实际拒绝、审查或私人动机的确定编造。explanation 明确接受 belonging、exclusion 或 mixture；不要求学生与参考答案保持同一个最终立场。

## 篇幅与难度

按实际 `answer` 字符串的空白分词计数，包含引导句和小标题：

| 题目 | 题干要求 | 参考答案实测 |
|---|---|---:|
| q1 | roughly 200–300 words | 395 |
| q2 | roughly 250–350 words | 459 |

即使考虑“roughly”的弹性，这也不是 H7A 354 对 350 那样的小幅偏差。参考答案可以比学生答案更详尽，但应明确标成扩展示范，或压缩到题目要求；现在同一个回答格式并未说明这种区别。

针对已会细读和比较叙事视角的本科入门研讨课学生，**q1 暂评中等，q2 暂评中等偏难；两者都不足以确认 hard**。q2 比 q1 多了双方材料比较；两题也确有论证与竞争解释任务。然而，公开方法说明直接给出了可用的解释、关键证据和禁止推断的结论，题干又逐段指定答题路线。q1 甚至直接给出需要比较的两种 we 解读。完成篇幅、复制概念标签和按步骤回答，都不能单独证明独立分析难度高。

这与 H7A 的观察一致：公开教学支架降低了学生自行发现解释和构建论证的负担。两题重点分别是策展人与志愿者，并非重复题；但共享的材料与反复出现的规则使第二题受到第一题提示，整份题组难度不能仅按单题 solver 标签累加。

## 后看自动审核与运行路径

- **q1：第 1 个候选即最终交付。** 初次 review 将 5 项都判为 `met`，但 5 段 `answer_evidence` 全部不在实际候选的 answer/explanation 中，全部逐字存在于独立 solver 的 answer/explanation。系统保留原始结果，并执行一次 `review_evidence_repair`；这次改为实际候选的引文，通过后才接受。最终对照对象应是修复后的 review，而不能将初次 review 作为候选已获有效验证的证据。
- **q2：第 2 个候选才最终交付。** 第 1 个候选因 `author_contract_invalid` / `difficulty_slot_mismatch` 被拒，错误记录为 `expected_slot: q1`（单题 worker 的局部契约）；没有进入 solve/review。此失败是协议失败，**不是参考答案事实错误**。第 2 个候选经过 solve/review 后通过。
- 最终两份 review 均为全部布尔条件通过、high、无 issues；分别 5/5、6/6 个 `met`。独立审核认可“各项任务实际出现”的覆盖结论，但补充了公共来源标签冲突、公开摘录不匹配、推论过强及 hard 证据不足。这些不能被逐字引文校验或单题通过状态抵消。
- 最终 review 实际都提醒了篇幅超出，却将其视为不阻断的表达问题；q1 自动估算约 375–390 词，q2 只称略超。精确篇幅应采用上述程序计数，不采用模型估算。

## 下一轮可测改进

1. **在最终组卷检查来源引用。** 为整份题组分配统一来源名称，或明确按题分组并绑定材料；检查题干提到的线索是否存在于实际公开摘录。加入当前 Source B 双义和 q1 缺失线索作为回归案例。
2. **区分解释容许性与事实断言。** 对 only、would、must 等强表述做语义复核，要求开放题反驳针对真实的竞争观点，允许“可共存但仍有张力”。另用程序检查篇幅；扩展示范须显式标识。
3. **评估去掉结论式提示后的难度。** 保留一般证据规则，减少直接给出解释和逐段路线的内容；固定学习者背景与材料，比较学生或教师标注下的难度，不把模型 hard 标签当成实验终点。
