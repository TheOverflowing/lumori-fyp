# H4b：冻结题目规格与程序生成答案

日期：2026-09-19。此项是 CPU 调度简答题的明确选择实验，尚未推广到所有课程或替换默认生成路径。

## 问题与改动

H2/H3 中，工具参数与最终题干不一致、正确表格搭配错误解释，以及未计算的附加子问都曾出现。H4a 改善检查顺序；H4b 进一步让关键事实有同一个来源。

1. Harness 作者只返回结构化参数、资料引用及资料是否充足，不编写自由文本答案。
2. `cpu_problem_spec.py` 严格验证进程、1–4 个场景、RR/STCF 规则、状态子问及可选约束选择；拒绝多余字段和不支持的规则。
3. 冻结规格、语言、目标难度、引用及计算工具契约，保存版本与 SHA-256。条件改变就重新计算，不能复用旧结果。
4. 程序执行全部场景，并据同一份规格生成中英文题干、时间线、指标、精确分数、剩余服务量、逐项约束判断和全部并列最优解。
5. 检查每个进程的服务量守恒，以及服务时间＋空闲＋切换开销＝最终完成时刻。所有场景合计最多 240 个时间线区间。
6. 独立 solver 仍从题干提取参数。控制器比较完整参数集合，允许 JSON 字段/进程排列及 STCF 默认零开销等无语义差异；缺场景、重复场景或改规则均不能通过。
7. review 收到所有有界轨迹；资料依据、教学适切性、难度与重复题检查继续生效。模型不能用自己的答案替换已编译答案。

当前所有选定场景都要求完整指标，因此题目仍可能偏长。编译器生成的目标难度标签和评分步骤仅符合格式要求，不能证明实际难度；最后仍须通过独立难度检查。

## 配置与使用

显式实验配置：`GENERATION_WORKFLOW=agent_v1`、`AGENT_RUNTIME=deepseek_harness`、`AGENT_QUESTION_SPEC=cpu_schedule_v1`，请求类型必须为简答题。一般课程保持 `AGENT_QUESTION_SPEC=none`。没有凭关键词自动猜课程，也没有更改本地生产 `.env`。

实际实验入口：

```sh
.venv/bin/python scripts/harness_correctness_experiment.py --live \
  --runtime deepseek_harness --question-spec cpu_schedule_v1 \
  --cases cpu_en_hard cpu_zh_hard --call-cap 18 \
  --harness-max-requests 4 --max-output-tokens 4096 \
  --output docs/agent/harness-experiments/H4B_20260919
```

省略 `--live` 时仅保存计划及快照。模式或编译器版本改变时，旧检查点不能继续使用。

## 验证边界

- 单元及集成测试使用预设模型响应，验证控制流、数据绑定和确定性计算；不作为真实模型准确率。
- 真实 H4b 使用既有中英文开发题组、冻结资料、`deepseek-flash`、thinking disabled、4096 输出上限，以观察结构化策略在原设置下的行为。
- H4b 同时改变作者提示、输出结构与渲染方式；不是只改一个提示词的消融实验。
- 独立的 M1 模型实验测试错误识别，直接调用各模型，不经过 Harness，也不测量生成质量或 RAG。
- 所有样本仍是 AI 整理的开发材料，尚无教师金标准或学生难度数据。

原始证据位于 `../harness-experiments/H4B_20260919/`，综合分析见 [H4b 与 M1 记录](PROGRESS_20260919_H4B_M1.md)。

## 验收与实验结果

最终相关回归 **233 passed**，含模型对比脚本检查；2 项既有依赖弃用警告，11.45 秒。[JUnit 结果](H4B_M1_VERIFICATION_20260919.xml)。

H4b 实际 17 次调用、153,851 token，全部 HTTP 200；提供商未报告费用。中英文各一题均完成规格编译，中文题通过完整生成流程，英文题因最终复核输出“解释文字 + 围栏 JSON”违反协议而未交付。该响应正常结束且未截断，不能混为答案错误或成功交付。

交付率 **1/2**。数值及题面核对见 [独立核查](H4B_INDEPENDENT_REVIEW_20260919.md)，它与模型自身门槛通过是两层证据，仍不属于教师验证。
