关键边界的独立人工交叉检查：

- q=1：P1 于 [0,1) 运行；t=1 到达的 P2 在 P1 重新入队前入队，所以先选 P2。切换 [1,3) 期间到达的 P3、P4 追加到仍在等待的 P1 后，故 P1 第二次运行在 [6,7)，P3 首次在 [9,10)，P4 首次在 [12,13)。
- q=2：P2、P3 在第一片尾前/恰好片尾进入队列，随后才重新入队 P1。下一执行者 P2 在切换前已选定，P4 在 [2,4) 切换期间追加到 P3、P1 后，因此 P4 首次到 t=16 才运行。
- q=1 不触发提前完成免收费：单个调度片的服务长度均为 1。最终同进程连续运行合并为 [69,72)，合并显示长度大于 1 不代表单次调度片超过时间片。
- q=2 的 P4 在 [44,45) 以 1<2 完成，下一次 P4→P3 转换免费但仍计入切换次数。q=4 的对应免费转换发生于 t=37。
- q=8 的 P2 在 [10,14) 以 4<8 完成、P4 在 [24,29) 以 5<8 完成，两次随后转换免费；P1→P2 与 P3→P4 收费，所以 4 次转换只收 4 单位开销。

2. 两条约束在这四个候选中都只排除 q1，任意删除其中一条，可行集合和最优方案均不变。约束数量为 2 不等于有两层独立冲突。
3. 最后一步主要是过滤并取最小数值；brief 要求的因果解释和多目标论证在学生可见内容中没有落实。
