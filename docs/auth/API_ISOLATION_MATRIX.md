# 账号边界与接口验收矩阵

日期：2026-09-18。适用：本地 FYP Education Studio 的注册、会话认证和账号数据隔离。

本矩阵由实际路由逐项整理，测试位于 `tests/test_account_isolation.py`。测试使用独立临时 SQLite 数据库、两个互不共享 cookie 的客户端、同一个应用实例，以及模拟的模型 HTTP 响应；不读取生产数据库，也不调用真实模型服务。测试客户端仅共用运行后台任务的事件循环，不共享 cookie 或认证请求头。

## 统一边界

- 未登录访问业务接口返回 `401`，包括有缺失字段或任意对象编号的请求；先认证，后处理业务输入。
- 已登录访问其他账号的对象返回 `404`，不回显对象是否存在、其内容、版本或处理状态。
- 账号自己的对象仍受版本、课程归属和审核状态等原有业务规则约束。
- 写入须携带当前会话的 `X-CSRF-Token`；跨来源或 `Sec-Fetch-Site: cross-site` 的写入被拒绝。其他账号的 CSRF token 不能使用。
- 如请求携带 `X-Account-ID`，该值必须与会话的账号相符，避免切换账号后的旧页面请求混入新账号。
- `request_key` 在账号内判断幂等性；两个账号可以使用同一个值，不能复用彼此的任务或发生跨账号冲突。
- 历史数据不会自动分配给第一个注册者；认领使用单独的、绑定邮箱的一次性本地授权令牌。

## 接口矩阵

| 方法与路径 | 归属依据 | 已登录的隔离验收 |
|---|---|---|
| `GET /api/status` | 会话用户的任务及调用记录 | `calls_today` 只计算本人调用 |
| `GET /api/courses` | `course_owners.user_id` | 只返回本人的课程 |
| `POST /api/courses` | 当前会话 | 新课程归属于创建者 |
| `GET /api/documents?course_id=…` | 课程所有者 | 外部课程返回 404 |
| `POST /api/documents` | 上传目标课程所有者 | 禁止向外部课程上传；相同文件按本人课程去重 |
| `GET /api/documents/{did}/chunks` | 文档所属课程 | 外部文档片段不可读取 |
| `POST /api/documents/{did}/index` | 文档所属课程 | 外部文档不可建立索引，不触发模型调用 |
| `POST /api/generations` | 请求课程及每一个文档 | 外部课程、外部/不存在的 `document_ids` 返回 404；本人其他课程文档保留 400 |
| `GET /api/jobs` | `job_owners.user_id` | 只列本人任务，先过滤再限制数量；课程过滤同样认证 |
| `GET /api/jobs/{jid}` | 任务所有者 | 外部任务的状态、错误和结果不可读取 |
| `GET /api/jobs/{jid}/evidence` | 任务所有者 | 外部任务的输入、检索证据及调用历史不可导出 |
| `GET /api/contents` | 内容所属课程 | 全部课程视图只列本人内容；外部课程筛选返回 404 |
| `GET /api/contents/{cid}` | 内容所属课程 | 外部内容及来源、配置、媒体信息不可读取 |
| `POST /api/contents/{cid}/review` | 内容所属课程 | 外部内容不能审核或保存新版本；不能通过版本冲突探测对象 |
| `POST /api/contents/{cid}/media` | 内容所属课程 | 外部内容不能生成媒体；媒体任务同样使用账号内幂等键 |
| `GET /api/media/{mid}/file` | 媒体→内容→课程 | 媒体原文件不可通过猜测编号跨账号下载 |
| `POST /api/media/{mid}/approve` | 媒体→内容→课程 | 外部媒体不可审核 |
| `GET /api/learn/{cid}` | 内容所属课程 | 已审核内容仍为账号私有，公开预览及显示答案均不可跨账号 |
| `POST /api/contents/{cid}/evaluations` | 内容所属课程 | 外部内容不可提交评价 |
| `GET /api/difficulty/evaluations/export` | 评价→内容→课程 | CSV 仅包含本人的逐题难度评价 |
| `GET /api/evaluations/export` | 评价→内容→课程 | CSV 仅包含本人的评价及备注 |
| `GET /api/contents/{cid}/evidence` | 内容所属课程 | 外部内容的来源、配置、历史修订及调用记录不可导出 |
| `GET /api/contents/{cid}/export` | 内容所属课程 | 外部 Markdown 和参考答案不可导出 |

## 会话与迁移验收

| 场景 | 必须满足的结果 |
|---|---|
| 未登录打开首页、静态脚本、`GET /api/auth/session` | 登录界面可用；会话返回 `user: null` |
| 注册 | 有效邮箱、15–128 字符密码和显示名称；邮箱按统一大小写处理 |
| 密码持久化 | scrypt 加随机盐；不保存明文密码；相同密码的两个账号散列不同 |
| 会话 cookie | HttpOnly、SameSite=Lax、Path=/；数据库只保存随机会话 token 的散列 |
| 登录失败 | 不存在的邮箱与错误密码使用相同错误结果 |
| 缺失或跨账号 CSRF token | 写入返回 403，无数据副作用 |
| 退出登录 | 服务端撤销会话；预先复制的 cookie 也无法继续访问 |
| 过期或伪造 cookie | 业务接口返回 401；不影响另一账号的会话 |
| 未认证认领历史数据 | `POST /api/auth/claim-legacy` 返回 401 |
| 一次性认领 | 绑定邮箱、验证 CSRF、只处理冻结的无所有者课程和任务；过期、已使用或被新令牌替代的链接无效 |
| 认领并发与冲突 | 两个同时消费者只能成功一个；快照对象已有所有者时整体回滚，不覆盖或部分转移 |
| 启动时的未归属任务 | 原有 queued/running 状态保留，不自动执行或触发模型调用 |
| 未绑定的历史记录 | 注册后仍不可见；原始课程、文档、片段、任务和内容保留 |
| 后台任务再次校验 | 即使持久化任务中的课程、文档或媒体编号被混入其他账号，执行前拒绝；已有账号时不执行无所有者的任务 |
| 幂等性 | 同一账号相同键和参数复用任务；不同参数 409；另一账号同键创建独立任务 |
| 越权副作用 | 课程、文档、片段、任务、内容、修订、媒体、评价和调用记录逐行保持不变 |

## 验收边界

这些测试证明所列接口的账号边界，并不代表完整渗透测试。应用的文件系统和服务端模型配置仍由本机管理员控制；目前没有邮件送达、邮箱验证、密码重置或账号管理后台。本次登录与注册不应被表述为已经验证用户对某个邮箱的所有权。

最终通过数量和运行结果以项目本次验证报告为准；本文不提前声明尚未执行的测试通过。
