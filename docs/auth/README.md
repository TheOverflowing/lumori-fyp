# 账号、会话与数据隔离

日期：2026-09-18。此模块在现有教学内容系统内提供统一账号；所有账号使用同一组功能，没有拆分教师与学生系统。

## 使用方式

启动 `./run.command` 后访问 `http://127.0.0.1:8765`，点击“创建账号”，填写称呼、邮箱和密码。密码为 15–128 个字符，可以使用中文或短语。注册成功后直接进入个人工作区；后续用邮箱和密码登录，左侧账号菜单可以退出。中文和英文界面共用同一账号。

新账号默认没有课程、资料或材料。自己创建的课程、上传的文件、RAG 索引、生成内容、修订记录、媒体、任务证据及评价导出只对该账号可见。学习视图目前也是私有的，尚未增加跨账号分享。

邮箱当前仅作为登录标识，尚未接入邮件验证、忘记密码或验证码服务。注册成功不等于系统已验证邮箱所有权。不要把此版本描述为带有邮件认证或账号恢复邮件的系统。

## 服务端设计

| 层次 | 实现 |
|---|---|
| 密码 | 每个密码独立随机盐；scrypt N=131072、r=8、p=1；数据库不保存明文 |
| 会话 | 32 字节随机不透明 token；服务端只保存 SHA-256 摘要；默认 7 天过期；退出立即撤销当前会话 |
| 浏览器 | HttpOnly、SameSite=Lax、Path=/ Cookie；会话 token 不写入 localStorage；接口响应禁止缓存 |
| 写操作 | 验证 Origin/Fetch Metadata 与当前会话绑定的 CSRF token；前端额外发送账号 ID 防止旧标签页误提交 |
| 认证限流 | 默认 15 分钟内每 IP 最多 10 次注册；每邮箱 10 次、每 IP 30 次登录尝试；数据库持久化窗口 |
| 课程归属 | `course_owners` 关联账号和课程；资料、片段、内容、媒体、修订与评价沿课程关系授权 |
| 任务归属 | `job_owners` 关联账号和任务；幂等键按账号分区；任务、调用记录与证据按账号过滤 |
| 后台执行 | 执行前重新核对任务账号、课程和所选资料，拒绝不匹配任务；Web 模式不执行未归属任务 |
| 检索 | 保持已有 RAG 策略，候选资料先限制到当前账号有权使用的课程和文档 |

未登录访问业务 API 返回 401；访问另一个账号的对象返回 404。过滤发生在服务端查询和文件下载端点中，不能通过替换课程、资料、任务或内容编号绕过。完整覆盖面见 [接口隔离验收矩阵](API_ISOLATION_MATRIX.md)。

前端在确认会话前隐藏工作区。退出、会话过期或切换账号会清空课程、草稿、弹窗、材料、通知及轮询；取消旧请求并验证响应所属的会话代数，阻止迟到响应回填另一个账号的页面。当前课程按账号保存，语言和外观偏好共用；跨标签页通过非敏感状态事件及页面重新激活时的会话检查同步。

`MAX_DAILY_API_CALLS` 现在按账号、UTC 日期统计。服务端仍共用本地配置的模型接口密钥，各账号的额度相加会增加全局调用量；该配置是次数限制，不是供应商费用封顶。离线实验直接使用无账号的 `Store`/`Pipeline` 时保留原有统计语义；Web 应用始终启用归属检查。

## 旧工作区的恢复

升级采用新增表，不修改原课程、资料、内容等表的列数，不自动将旧数据交给第一个注册账号。旧数据在指定归属前保留但不可从新账号读取；未归属的 queued/running 历史任务也不因启动服务而改变状态或执行。

本次旧工作区归属由用户明确指定为 `18518378519@163.com`。本地管理员使用以下命令生成一次性恢复文件；用户在页面自行设置密码，不需要向开发者提供密码。

```sh
# 只读查看数据数量与已有归属
.venv/bin/python scripts/manage_accounts.py status

# 先停止应用，再备份并准备恢复文件。输出路径须为不存在的新文件。
.venv/bin/python scripts/manage_accounts.py prepare-legacy \
  --email 18518378519@163.com \
  --output tmp/account-recovery/restore-workspace.html

./run.command
```

工具使用 SQLite backup API 备份数据库，复制资料/媒体文件，检查原有业务表逐行指纹及数据库完整性。备份保存在 `tmp/account-backups/`。HTML 文件权限为 0600，包含本地恢复凭证，不能提交仓库或转发。命令输出只显示文件位置、数量和检查结果，不打印 token。

打开 HTML 中的链接，使用指定邮箱注册或登录后恢复。恢复 token 通过 URL fragment 传递，页面读取后立即清除地址栏，仅暂存在页面内存；不会以 URL 查询参数送到服务端访问日志。随后以经过会话与 CSRF 验证的 POST 提交。刷新页面丢失内存 token 时，可重新打开本地 HTML。

恢复仅绑定签发时冻结的无所有者课程及其任务。邮箱必须匹配，token 只使用一次；默认有效期 7 天，可用 `--ttl-hours` 缩短。本地重新签发后旧链接失效。对象归属已变化时整笔事务回滚，不覆盖其他账号。成功后所有原资料和生成内容沿课程归属可见；生成与媒体不会被重新调用。

备份还原需先停服务并另存当前 `data/`，再从选定备份还原数据库及 documents/media。不要让旧 SQLite WAL/SHM 文件与恢复数据库混用。恢复会回到备份时状态，之后新增的账号和数据需要单独保留。

## 配置与脚本

`.env.example` 已列出 `AUTH_COOKIE_NAME`、`AUTH_COOKIE_SECURE`、`AUTH_SESSION_HOURS` 与限流配置。本地 HTTP 使用 `AUTH_COOKIE_SECURE=false`；HTTPS 环境启用 `true`。当前服务继续仅监听本机，正式网络部署还需配置受信任主机、代理与 HTTPS。

CA1 与难度验收脚本仍默认使用独立临时数据库，并通过真实认证 API 创建临时账号、发送 CSRF、结束后撤销会话；随机密码及会话 token 不记录到实验结果。`scripts/ca1_smoke.py --live --use-app-data` 必须显式提供现有账号：`FYP_SMOKE_ACCOUNT_EMAIL`、`FYP_SMOKE_ACCOUNT_PASSWORD` 环境变量，或 `run_live` 的对应参数。不要把密码写入命令历史或证据文件。登录失败不会退回注册；使用应用数据时仍须先停止普通服务。
