# 难度控制研究 · Difficulty control experiments

本目录保存难度提示词与评测研究，和日常应用数据、现有生产提示词分开。当前的目标是比较 **AI 评审下的目标难度一致性及有效达标率**，不是宣称已校准学生实际难度。

## 已实现的研究工具

- 六种等生成次数的提示词：当前基线、难度维度约束、评分要点先行、三档对照、支架与迁移控制、输出前自检。
- 固定课程上下文、相同请求，随机化运行顺序；独立模型只看匿名题目和资料，不看作者目标或策略。
- 保存请求总数、有效输出、无法判断、失败、逐题原稿、评审结果、完整提示、模型标识、调用用量、耗时和平台返回费用。
- 失败保留在分母；成本缺失单独标记；独立评审结果可再次交由熟悉课程的人盲审。
- 离线汇总重算不调用 API；不会将重算当作新实验。

当前提示版本为 `difficulty-experiment-v2`，补充了所有策略共用的完整材料输出条件。D1 原结果来自 v1，原始代码与结果均保留；v2 只跑了一个需求的小范围验证，不能将其当作六需求 D1 的重测。

## 范围

本轮只做小规模开发筛选。多调用规划、局部修订、多候选筛选及 GEPA/ProTeGi/MIPRO/OPRO 自动搜索已进入研究计划，尚不能写为已实现或已验证效果。保留集不用于提示词调整。只有经过更大样本、重复实验与评审校准，才考虑更新默认生产策略。

运行入口：`scripts/difficulty_experiment.py`；不加 `--live` 只展示实验规模，不调用付费模型。
