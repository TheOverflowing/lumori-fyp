# 难度评估标准 v2（实验版）

版本：difficulty-judge-v2-pilot-20260924。状态：待教师校准；不替换生产 v1，不宣称实测难度或教师验证。

## 三个独立结果

1. **认知要求**：学生完成题目全部必要要求时，至少需要什么认知活动？分别记录复现、熟悉应用、策略推理、持续探究。受 DOK 启发，但不是正式 DOK 认证工具。
2. **模型预估难度**：相对于明确的先修知识、练习经验与作答条件，输出 easy / medium / hard / uncertain。不能将认知类别直接映射成难度。
3. **实测难度**：没有目标学生群体的真实作答数据时为空。模型模拟、重复一致、引用正确都不能补上这个字段。

## 评审步骤

- 先判断题目是否可评：缺少决定答案的条件、矛盾条件或无法完成的要求，记录 invalid_question；学生准备情况不足则 insufficient_profile。允许有依据的开放解释、明确要求条件性回答，不因此判错。
- 区分学生可见题干/材料和评委私有参考。不可拿私有资料填补学生看不到的条件。
- 列出题干已经提供的事实、方法和答案性提示；引用确切原文。
- 列出学生必须独立完成的要求；不得用参考答案中可选的高阶发挥抬高要求。
- 分别说明知识整合、策略选择、论证要求；不按维度数量、字数、动词或机械步骤数打分。
- 给出预估等级、相邻档位辨析以及尚存的不确定性。无可靠边界时弃判，不默认中等。

## 暂定操作标准

| 等级 | 相对于已声明学生背景的最低必要任务 |
|---|---|
| easy | 直接提取、解释或熟练复现，独立选择较少 |
| medium | 有实质要求的熟悉应用、比较与分析 |
| hard | 对该群体需要显著的独立整合、非例行策略或有证据的论证 |
| uncertain | 条件/背景不足，或相邻档位之间缺乏可靠判断依据 |

这些描述不是教师确认的参照题，也不是答对概率阈值。未学过的冷门知识可能很难，但不能据此宣称认知要求高。人文的证据权衡、数学的证明与策略选择、计算机的约束与不变量分析均可体现高要求；不把工程方案比较当成 hard 的唯一形式。不需要课外知识不能成为降级理由。

## 评委独立性和可审计性

- 盲评输入只含学生背景与学生可见题目；隐藏目标等级、作者设计、历史评委意见、文件名及题目变式关系。
- v2 强制保存原文引用及简短依据；宿主核验引用确实存在。引用校验只保证字符串来源，不证明解释正确。
- 第一轮评委独立作答。有分歧时可增加另一模型/教师复核，但须在独立标注集上验证收益，不把多数投票当真值。
- confidence 仅为模型自报，不显示成概率。明确展示弃判率与有效覆盖率。
- 不因要求 hard 而改变评分标准；不因校准未完成直接强制更改正式生成标签。

## 教师校准计划

初步收集 30–60 道覆盖学科、语言、题型和边界情况的题，规模仅为起步建议，不代表统计充分。每题由两位相关学科教师独立评审（先修背景必须相同）；分别记录认知要求、预估难度、题干提示、相邻档位理由和弃判原因。先保存原始分歧，再讨论仲裁，不以模型输出代替任一教师。

参照/开发集与最终测试集按题目家族、材料来源分离，同题改写不能跨集合。当前 8 道均是 diagnostic 开发题，不能后续冒充未见测试题。当前没有教师确认参照题，所以试验提示中明确缺失这一条件。

准确性以独立教师判定为暂定参照：报告混淆矩阵、加权 κ、宏平均指标、有效覆盖率，分学科/语言报告；先报告教师间一致性。弃判和格式失败都保留在分母，另报有效判断中的一致程度。阈值应在标注后预先登记，不能观察测试结果后挑选最有利门槛。

真实学生试用阶段按评分规则记录得分比例、常见错误、作答条件和学生背景；开放题先检查评分者一致性。有足够数据且模型假设适合时再考虑 IRT / 部分得分模型；不将少量样本硬拟合成可靠的题目参数。

## 首轮诊断预先约定

8 道固定题 × 2 种评审流程 × 2 次独立重复 = 32 次调用，上限 32，无自动修复/重试。两个版本相同模型、thinking off、temperature 0、输出上限 6000；固定随机顺序。temperature 0 不保证服务完全确定。调用数上限并非金额上限，服务未返回费用时报告未知。

v1 使用归档 R8 的原始 solver 系统提示、量表及 schema，更换为当前诊断题，清空私有参考；v2 使用独立证据式评审。两者通过相同 ApiProviders 接口评审，不执行 ACP Harness 或解题工具。本轮比较整个评审设计，无法单独归因于某一句提示或 schema 变化。v1 的 answerable/ambiguity/条件检查不通过时归一成弃判，同时保留原始难度标签；v1 原 schema 不支持难度不确定，这种不对称必须保留说明。

观测项：输出有效率、完整重复一致率、明确等级且一致率、弃判率、仅改表述时的一致性、增加解题提示后的难度不升高。支持不升高也可能因为评委对全部题都打同一档，因此同时报告等级分布和单题轨迹，不把这个指标独立当成功。所有对照关系都是开发假设，尚未经教师确认。每题只重复两次，不能得出长期稳定结论。

## 文献与应用依据

- [Webb 等：DOK 的正确使用，2023](https://www.edutopia.org/article/how-use-norman-webb-depth-of-knowledge)：认知复杂度不同于实际难度，不能按动词定级。
- [G-Eval，EMNLP 2023](https://aclanthology.org/2023.emnlp-main.153/)：借鉴结构化评价形式；不是教育难度效果的直接证据。
- [Judging LLM-as-a-Judge，2023](https://arxiv.org/abs/2306.05685)：评审偏差与评委验证。
- [LLaSA，Findings of EMNLP 2024](https://aclanthology.org/2024.findings-emnlp.477/)：模拟不同水平学生估计题目难度；本项目尚未复现，模拟不等于学生实测。
- [ENEM 难度评估研究，2026 预印本](https://arxiv.org/abs/2602.06631)：相对排序和绝对校准需分别验证，不能直接泛化到本项目。
- [Moodle 题目统计](https://docs.moodle.org/en/Quiz_statistics_report)：作答得分、区分度、错误模式。
- [NAEP IRT 技术文档](https://nces.ed.gov/nationsreportcard/tdw/analysis/scaling_irt.aspx)：基于作答数据估计题目参数及检查模型适配。
