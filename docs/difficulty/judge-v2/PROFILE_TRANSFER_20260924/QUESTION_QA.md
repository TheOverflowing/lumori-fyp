# 新题可解性检查（不作为难度标签）

本文件是题目质量的辅助检查，未提供给评委，也不改变运行前 PLAN.md 的预期或等级标准。

- 奇数和：基例 n=1；若前 n 项和为 n²，则加上下一项 2n+1 后为 (n+1)²。有限举例不覆盖任意正整数。各背景都具备相应代数和归纳法前提，练习经历不同。
- 二分边界：原算法在 [1,3]、t=3 时 l=0、r=1 不前进；单元素且 t 大于所有元素也会错误返回 0。可改成半开区间 l=0、r=len(a)，小于 t 时 l=m+1，否则 r=m。循环中 l 左侧均小于 t，r 及右侧均不小于 t；区间每次严格缩小，结束 l=r 得最小满足索引或 n。重复元素不会破坏该不变量。另有有限枚举与线性扫描对照，见 QUESTION_QA.json；该检查不能当成无限输入的形式证明。
- 辅导因果：观察比例分别为 90% 和 60%，差 30 个百分点。自愿参加没有控制组间原有差异，不能据此认定因果增益；学习动力等只能作为可能解释，不能写成观测事实。可提出在明确目标学生中随机分配辅导机会并比较结果的设计，说明随机分配旨在平衡已知/未知混杂。样本误差、实施偏差等仍需另外考虑，但题目未要求完整研究方案。
- 车站记录：同时期日志支持当时存在交货和测试不确定性，不能证明负责人已知永久关闭；日记可记录当时听到的说法，但不能直接显示负责人掌握的信息。事后未重开也不能单独证明事前欺骗。两种解释可分别在“负责人知道不确定性却有意误导”和“作出过度乐观但真诚预测”的假设下成立，需通信记录等补充证据。不是因为只有一项解释成立才允许作答。

这些说明仅检查题目有可行的回答路径，不能提供教师难度或学生通过率。
