# v3 方法改进记录

## 问题

上一轮 v2 能摘录题干已给出的解释，却在“剩余任务”中又说学生要生成同样的解释。单独列出 supplied_support 与 remaining_demands，不能保证两者相互核对。AI 评审据此提出修改，但其标签本身不是独立金标准。

## 变更

新增 scripts/difficulty_judge_v3.py，保留 v2 作为对照。每项要求记录：原文 → 对应解法提示 → 已提供程度 → 剩余任务。增加简短合格作答示例及相对于学生背景的难点说明。hard 必须引用一个确有剩余工作的要求。

确定性校验会拒绝不存在的支持原文、已完整提供却仍重复计算的任务、遗漏/重复的审计条目和无法关联剩余要求的 hard。它不把提示多少直接转换成等级，也不强制接受上一轮 AI 的 medium 判断。

比较工具支持 v1-v2 与 v2-v3 两种模式、指定冻结题集，并在每次调用前保存输入；现有 v1-v2 模式保持可运行。新协议和汇总边界测试与旧测试合计 16 项。

## 隔离

正式 Agent 生成逻辑、.env 与历史实验结果没有被该改进覆盖。校准文件中的 human_teacher=false / independent_blind_review=false 继续保留。原始题集的 teacher_label 仍为空。

## 本轮范围

2 道旧回归题加 6 道新题，最多 32 次真实调用。新题覆盖文字证据、数学证明和并发设计；每个新家族都有完整或较强解法提示对照。所有题为 AI 编写，验证的是评审流程行为，不能代替学生难度校准。查看 V3_TRANSFER_20260924/REPORT.md 获取实测调用与结果。

## 完成后的汇总规则

新增 scripts/difficulty_review_decision.py：重复结果齐全、全部有效且等级一致才能形成 AI 暂定一致；分歧、缺失或失败返回待复核，不能静默选成功的一次。这是实验结果的确定性后处理，不改变实时请求。新增 7 个边界测试，与原协议测试共 23 项通过。

本轮 32 次调用、100,674 tokens；v3 14/16 有效、v2 15/16 有效。v3 尚未提升稳定性，保留实验状态。具体负面结果、剩余边界与保守汇总见实测报告。
