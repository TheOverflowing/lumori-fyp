## 判读与接入决定

- **稳定性没有观察到提升**：v1、v2 都是 8/8 题在两次重复间一致。低温设置、样本小、同一个服务和可能存在的服务确定性均限制结论。
- **提示敏感性出现有用差异**：数学原题及改述题两种方法均判 medium；加入完整恒等式、上界和等号条件后，v1 仍 medium，v2 两次均 easy。这符合本次开发假设，但没有教师标签，不能称为准确率提升。
- **背景不足时会保留不确定性**：缺学生背景的题 v1 两次 medium，v2 两次 uncertain。缺必要条件的题，两套流程都能识别；v1 原始标签仍按原 schema 保留，报告等级按可答性检查归一成 uncertain。
- **人文边界仍未解决**：无教学提示、加阅读前言、恢复教学提示三个版本全部 hard。增加提示后的“不升高”检查全部通过，但没有证明它能分辨提示强弱。v2 能正确摘出教学提示已给出两种解释，却又在剩余任务中说学生需要“生成”另一解释；这可能高估独立任务。具体写作和证据论证是否仍足以达到 hard，需要学科教师对同一学生背景判断，不能为了得到下降结果继续调提示。
- **不跨实验混作同条件复测**：此处 h_hint 保留了 R8 已接受候选的学生题干，但历史 R8 使用 high 思考与 Harness 包装；本轮为 off、temperature 0、直接 API、私有参考清空。因此历史 medium 与本轮 hard 不能归因于单个因素，也不能单独证明同输入随机波动。
- **当前收益是可审计性**：v2 16/16 次结构与原文引用校验通过，能够定位上述“已提供解释但又称需生成”的争议。原文匹配不验证解释或难度是否正确。

接入决定：保留 v2 为实验评审器，不自动替换生成流程的正式难度门槛。先由两名教师独立评阅匿名题包，记录分歧和仲裁；之后另建与参照材料隔离的测试题，再评估准确性和跨题泛化。教师尚未参与，本轮没有可报告的教师一致性、准确率或实测难度。
