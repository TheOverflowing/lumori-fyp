## 可查看与回滚

- /api/jobs/{id}：简短旁路状态。
- /api/jobs/{id}/evidence：完整输入、输出、原文引用、计量与阶段调用 ID。
- /api/contents/{id}：旁路摘要；编辑内容后 matches_current_content=false。
- /api/contents/{id}/evidence：导出原旁路观察，标记对应最初生成版本。新增内容导出和版本失效逻辑由本地 API 检查验证；真实调用验收直接核验的是任务证据接口。

本次没有新增前端自动判级或返工交互。将 DIFFICULTY_SHADOW_MODE 改为 off 并重启可关闭未来旁路；旧任务不会因为开启开关而自动收费。
