# AI 教师式逐题复核与校准依据

评审者为 Codex，不是真人教师。我在填写前已看过原评委和旁路评委的结果，因此本轮**不是盲评或独立金标准**。判定仍从 `blind_packet.md` 中的学生背景与学生可见题目出发，单独检查最小合格答案所需的剩余工作。逐题结果保存于 `ai_teacher_style_review.csv`；原有空白 `teacher_review_template.csv` 保留给未看过模型结果的评审者。

| 样本 | 可评性 | 认知要求 | AI 教师式难度 | 校准用途 |
|---|---|---|---|---|
| 索引版本与课程范围 | 可评 | 熟悉应用 | 暂定中等 | 开发参照，不能当教师真值 |
| 相似命中与证据缺口 | 基本可评，资料归属表述有歧义 | 熟悉应用 | 暂定简单 | 修题前排除出准确率计算 |
| TCP 两类窗口 | 可评，零窗口问法需限定 | 熟悉应用 | 简单／中等边界 | 仅用于边界讨论；困难不成立 |

## 索引版本与课程范围

题前材料已写明不可混用模型版本、应重建索引、权限不会因重建扩大、停用或删除资料不可用、相似度不等于答案正确。合格答案仍需把这些规则共同应用到含新旧版本、两门课程、删除和停用资料的情境，并区分既有规则与尚待核验的实际状态。画像明确说学生尚未独立处理过混合情境，所以我暂判中等。若课程已反复练习同型组合，可能偏简单；没有证据支持困难。

参考答案有一处可收窄的表述：将“另一门课程的资料”附上“若它又属于当前课程”式例外，容易混淆资料记录与同内容副本。更清楚的说法是：另一门课程的资料不因术语相同而成为本课程依据；若当前课程另有合法启用的副本，应按该副本的权限和状态单独核验。此项是答案表述质量，不是难度分值。

## 相似命中与证据缺口

对给定学生，版本不一致、无权限、已删除分别对应材料中明示的排除条件。得出“该命中不能用”的结论不需要选择新方法；后续缺口处理和多解释原则也可直接从材料提取。我暂判简单，不能因规则条目多就升为中等。

题干同时说命中记录来自另一门课，又说“该资料在当前课程中已被删除”，没有明确后者是同一记录还是当前课程曾有的同内容副本。核心结论不受影响，但对删除状态的解释会分叉。建议改成“当前课程曾保存一份同内容副本，现已删除；这次命中实际来自无权限的另一门课”。修订前本题只作问题诊断，不计入难度准确率。

## TCP 两类窗口

已展示的规则直接给出两窗口取较小值及较小者为限制方；三种数值状态都可逐一套用。学生仍需组织“读取慢→缓冲被占用→通告窗口收缩→正常发送受阻”的因果链，并说明限制方转移。完整的原始课程节选已有这条因果链；题前短摘录没有完整写出。画像只说“已学习所给课程资料”，未说明学生对该链条的练习程度。因此我保留简单／中等边界：若已熟练掌握完整资料，偏简单；若需要独立补全因果解释，偏中等。两种情况下都缺少足以判困难的非例行瓶颈。

题目问“通告窗口为 0 时能否发送数据”，参考答案多次写“不能发送任何数据”。按题目所依教学节选，这是一种简化说法；作为真实 TCP 的绝对陈述则不严谨。RFC 9293 第 3.8.6.1 节要求支持零窗口探测，发送端可为探测发送至少一个字节或重传。[RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html#section-3.8.6.1) 建议把题干限定为“按本材料的常规数据发送模型，不讨论零窗口探测，窗口为 0 时能否正常发送新的应用数据？”；参考答案相应改为“不能按正常窗口发送新的应用数据”。修订前，这道题不宜作精确难度锚点。原始草稿保持不变，以免覆盖实验记录。

## 校准后如何使用旁路证据

1. **先检查题目和答案，再比较难度。** 资料归属歧义与零窗口绝对表述分别进入题目／答案质量清单，不能让难度分歧掩盖它们。旁路语义复核只审其难度判断，返回 `no_issue_found` 不代表参考答案正确。
2. **按学生已经学过和实际可见的材料扣除现成解法。** “解释”“比较”“五个小问”不自动等于困难；明确要求仍需学生做的选择、整合与论证。
3. **保留边界和弃判。** 当前最有价值的稳定信号是网络题三次旁路候选均不包含困难；这支持优先人工复核发布标签，不能单独证明旁路评委准确。
4. **不计算教师准确率。** 三题都是开发中已曝光给评审者的样本，第二、三题还需修订。应另留未见题、未见模型结果的教师评审及明确学生先修／练习背景，才计算与教师的一致性。
