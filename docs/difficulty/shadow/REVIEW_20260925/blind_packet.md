## REAL_TASKS_20260924_R2_task_1_q1

**学生背景**

已学习所附课程资料的本科生，能理解模型版本、课程权限和引用定位规则，尚未独立处理过混合情境。

**学生可见内容**

Learning objectives:
能依据索引版本一致性与课程隔离规则，判断新旧向量混用检索是否可行。
能针对更换嵌入模型的情境，提出当前课程索引重建与检索范围限定的处理方案，并说明核验与引用定位要求。

本课程的操作性规则要点
向量索引中的文档向量由指定版本的嵌入模型生成；查询向量必须由同一嵌入模型版本生成，才能在该索引中比较相似度。更换嵌入模型后，应为需要使用的课程资料重建向量索引并记录新的模型版本，不能把新查询向量与旧文档向量混合检索。

检索应限定在当前账号有权限访问的当前课程资料中，只使用已启用且未删除的资料；另一门课即使出现相同术语，也不能自动加入当前题目的依据。索引重建不会扩大资料权限，也不能恢复已删除资料。

重建后的核验与证据检查
如果索引版本不一致，应先确认模型与索引版本，再重建对应课程的索引，完成后检查索引版本和检索范围。这个过程应保留原文和来源标识，使每个引用都能定位到正确资料。

检索相似度较高只说明文本相近，不自动证明答案正确。资料不足时应明确说明缺口并补充有权限的资料，不能编造事实或从无权限课程取用文本；对多种可行解释，应指出各自依据和不能确定的部分。

某本科生所在课程刚把生成文档向量的嵌入模型换成新版本，但课程资料库中此前建立的向量索引仍由旧版本模型生成，且尚未重建。该生当前账号可以访问本课程资料与另一门课程的部分资料，本课程资料中有一份已被删除的讲义和一份被停用（未删除）的资料；另一门课程出现过与本次问题相同的术语。该生打算直接用新版本的查询向量去检索旧索引中的向量，并把返回的相似度较高片段直接作为答案依据。

请依据本课程资料中的操作性规则，回答下列问题：

1. 直接使用新查询向量检索旧索引是否可行？请说明模型版本一致性方面的理由。
2. 请给出更换嵌入模型后对当前课程索引与检索范围的处理方案，并说明该方案对资料权限、已删除与已停用资料的影响。
3. 请说明重建后需要核验的环节，以及为什么相似度较高不能自动作为答案正确的证明；当资料不足时应如何处理。

要求：回答应区分资料中明确规定的规则与你的推断，并说明方案中哪些环节需要实际核验才能确认。

## REAL_TASKS_20260924_R2_task_2_q1

**学生背景**

已学习所附课程资料的本科生，能理解模型版本、课程权限和引用定位规则，尚未独立处理过混合情境。

**学生可见内容**

Learning objectives:
能依据嵌入模型版本与索引版本的一致性，判断一次高相似度命中是否可作为本课程的检索依据。
能结合当前课程权限与资料启用/删除状态，判断命中文本能否进入引用。
能在证据不足时说明引用可用性、缺口处理方式与不能确定之处，且不编造事实或使用无权限文本。

课程检索与证据检查规则
1. 文档向量由指定版本的嵌入模型生成；查询向量必须由同一嵌入模型版本生成，才能在该索引中比较相似度。
2. 更换嵌入模型后，应为需要使用的课程资料重建向量索引并记录新的模型版本，不能直接用新查询向量与旧文档向量混合检索。
3. 检索应限定在当前账号有权限访问的当前课程资料中，只使用已启用且未删除的资料；索引重建不会扩大资料权限，也不能恢复已删除资料。
4. 索引版本不一致时，应先确认模型与索引版本，再重建对应课程的索引，完成后检查索引版本和检索范围。
5. 检索相似度较高只说明文本相近，不自动证明答案正确。生成答案时要检查题干条件是否完整、答案是否得到资料支持、引用是否准确。

引用定位与资料缺口处理
1. 检索与重建过程应保留原文和来源标识，使每个引用都能定位到正确资料。
2. 资料不足时应明确说明缺口并补充有权限的资料，不能编造事实，也不能从无权限课程取用文本。
3. 对多种可行解释，应指出各自依据和不能确定的部分。
4. 以上为本课程的操作性规则，不涉及外部行业法规。

某课程检索系统的一次操作记录如下：

- 当前索引中的文档向量由嵌入模型 A 生成。
- 本次查询向量由嵌入模型 B 生成，索引尚未按 B 重建，新模型版本也未记录。
- 命中文本来自另一门课的资料库；当前账号对该课程没有访问权限。
- 该资料在当前课程中已被删除。
- 命中文本与题干术语高度相似，相似度分数很高。
- 命中文本的原文与来源标识被保留，引用可定位到资料库中的该条目。

请结合课程资料中的检索索引、课程隔离与证据检查规则，回答：这条高相似度命中能否作为当前题目答案的引用依据？需要补充或修正哪些条件？在资料仍不足时，应如何说明缺口与处理方式，以及如何对待存在多种可行解释的情况？

请分点作答，并说明每条判断所依据的规则。
