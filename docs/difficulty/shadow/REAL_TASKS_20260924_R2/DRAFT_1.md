# 更换嵌入模型后，如何处理当前课程的索引与检索范围。请出一道条件完整、要求应用资料规则的中等简答题。

状态：真实任务生成的待审核草稿；未进行教师或学生验证。

## 本课程的操作性规则要点

向量索引中的文档向量由指定版本的嵌入模型生成；查询向量必须由同一嵌入模型版本生成，才能在该索引中比较相似度。更换嵌入模型后，应为需要使用的课程资料重建向量索引并记录新的模型版本，不能把新查询向量与旧文档向量混合检索。

检索应限定在当前账号有权限访问的当前课程资料中，只使用已启用且未删除的资料；另一门课即使出现相同术语，也不能自动加入当前题目的依据。索引重建不会扩大资料权限，也不能恢复已删除资料。

## 重建后的核验与证据检查

如果索引版本不一致，应先确认模型与索引版本，再重建对应课程的索引，完成后检查索引版本和检索范围。这个过程应保留原文和来源标识，使每个引用都能定位到正确资料。

检索相似度较高只说明文本相近，不自动证明答案正确。资料不足时应明确说明缺口并补充有权限的资料，不能编造事实或从无权限课程取用文本；对多种可行解释，应指出各自依据和不能确定的部分。

## 题目

某本科生所在课程刚把生成文档向量的嵌入模型换成新版本，但课程资料库中此前建立的向量索引仍由旧版本模型生成，且尚未重建。该生当前账号可以访问本课程资料与另一门课程的部分资料，本课程资料中有一份已被删除的讲义和一份被停用（未删除）的资料；另一门课程出现过与本次问题相同的术语。该生打算直接用新版本的查询向量去检索旧索引中的向量，并把返回的相似度较高片段直接作为答案依据。

请依据本课程资料中的操作性规则，回答下列问题：

1. 直接使用新查询向量检索旧索引是否可行？请说明模型版本一致性方面的理由。
2. 请给出更换嵌入模型后对当前课程索引与检索范围的处理方案，并说明该方案对资料权限、已删除与已停用资料的影响。
3. 请说明重建后需要核验的环节，以及为什么相似度较高不能自动作为答案正确的证明；当资料不足时应如何处理。

要求：回答应区分资料中明确规定的规则与你的推断，并说明方案中哪些环节需要实际核验才能确认。

## 参考答案

1. 不可行（至少在旧索引上直接比较相似度不可靠）。按照课程规则，文档向量由指定版本的嵌入模型生成，查询向量必须由同一嵌入模型版本生成，才能在该索引中比较相似度；因此不能直接拿新查询向量与旧文档向量混合检索。

2. 处理方案：先确认当前模型与索引的版本，再为需要使用的课程资料重建向量索引，并记录新的模型版本；检索范围限定在当前账号有权限访问的当前课程资料中，只使用已启用且未删除的资料。索引重建不会扩大资料权限，也不能恢复已删除的资料，因此那份已删除的讲义不应因重建而重新可用；被停用（未删除）的资料属于规则中的“未启用”情形，不应纳入检索使用的资料。另一门课程即使出现相同术语，也不会因此自动加入当前题目的依据，除非它本来就在当前账号有权限访问的范围内、且属于当前课程资料。

3. 重建后应检查索引版本与检索范围，确认查询与文档使用同一模型版本；同时保留原文和来源标识，使每个引用都能定位到正确资料。相似度较高只说明文本相近，不自动证明答案正确，因此生成答案时还需检查题干条件是否完整、答案是否得到资料支持、引用是否准确。资料不足时应明确说明缺口，并补充有权限的资料，不能编造事实或从无权限课程取用文本；若存在多种可行解释，应指出各自依据和不能确定的部分。

上述关于“已删除讲义不恢复、被停用资料不纳入检索”的结论直接来自规则中的已启用且未删除限定与重建不扩大权限、不恢复已删除资料的表述；而具体用哪一版模型、重建是否成功、权限范围是否变化，属于需要实际核验才能确认的环节。

## 解析

要点一：模型版本一致是检索可行的前提，文档向量与查询向量须出自同一嵌入模型版本，所以新查询向量不能直接检索旧索引中的旧文档向量。

要点二：正确做法是为需要使用的课程资料重建索引并记录新模型版本，同时把检索限定在当前账号有权限访问、已启用且未删除的当前课程资料；重建不扩大权限、不恢复已删除资料，被停用资料也应排除，同术语的其他课程不会自动成为依据。

要点三：重建后核验索引版本与检索范围，保留原文与来源标识保证引用可定位；相似度高只是文本相近，仍需检查题干条件完整性、答案资料支持与引用准确性；资料不足时说明缺口并补充有权限资料，不编造、不越权取用，多种解释时说明各自依据与不确定部分。

评分时可接受把“已停用资料”按“未启用”排除的表述；若考生说明该细节需以实际资料状态核验，也符合本题对核验环节的要求。
