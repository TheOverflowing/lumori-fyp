# 难度自动返工候选规则与上线门槛（草案 v1）

目标是在生成草稿时，只有证据足够且预算允许，才为**难度不匹配**的题目启动至多一次额外返工。题目有效性、参考答案正确性、引用有效性和教学难度必须分别检查；返工候选不等于这些质量检查通过，更不是自动发布许可。

## 当前已实现：影子决策，不执行返工

新任务可选择在旁路中增加一次**同提示、同模型**的难度判断及其理由复核。默认关闭，必须显式设置 `DIFFICULTY_SHADOW_REPEAT_DISAGREEMENTS=true` 且旁路调用上限至少为 4。只有原评委与目标难度不一致、第一旁路评委的候选不含目标、第一次语义复核无发现时才调用第二次难度评审。第二次不可用、理由复核有问题或结果分歧时保留人工复核。它们共享冻结的任务预算和调用记录，不自动重试可能计费的中断请求。

离线决策只在以下条件全满足时标为 `rework_candidate`：题目可评；原评委与目标不符；第一次旁路候选不含目标；第一次难度理由语义复核无发现；第二次评审可用、可评，候选集合与第一次一致，且第二次理由复核也无发现。否则给出 `manual_review` 或 `no_difficulty_rework` 及原因。两个相同模型的回答只能表明重复一致，**不能代替独立教师或答案正确性验证**。所有决策均写明 `enforcement_enabled=false`。

当前 `COUNTERFACTUAL_20260925_R3.json` 读取保存的草稿和重复评审，零新模型调用：三道已保存题目中，两道没有达到候选条件；网络题虽有重复且候选集合相同，却没有第二次理由复核，仍留在人工复核。该题的零窗口参考答案还存在绝对化表述，且我的教师式评审非盲，因此当前**可作为正式自动返工依据的样本数为 0**。数据库简单选择题只得到失败的计划，没有草稿或旁路判断，不能算进三道已评题。首轮 `COUNTERFACTUAL_20260925.json` 使用过宽的单次审计规则，保留为历史开发记录，不作为当前决策。

## 执行自动返工前的必要控制

1. **独立质量门槛**：在使用难度判断前，明确题目条件、参考答案和引用的复核状态。难度评委的语义审计只审评委理由，不承担答案事实核查。若内容质量状态未知或有争议，转人工复核。
2. **一次且有预算的返工**：控制器预留新作者、独立解题、内容审核和再判级所需的总调用额度；不足则保留已核验草稿并提示人工，不开一半的返工。任务取消、资料权限或版本变化都必须停止后续调用。重复请求与恢复不可重复收费。
3. **冻结目标和来源**：返工不得改变用户要求的题数、题型、目标难度、课程权限和已冻结的证据范围。新题必须再次通过现有正确性、答案、引用、去重和难度门槛；原草稿、旧评审和返工调用都留在证据中。
4. **明确失败处理**：返工后仍不匹配或任一步不可用，不把目标标签冒充已达成等级；只保留一个标有偏差的待审核草稿，或返回明确的需人工处理状态。不得循环增加调用次数。
5. **版本与回滚**：只对创建时冻结了新规则的新任务生效；旧任务恢复不新增未授权调用。开关可关闭后续返工，历史证据仍可读。用户编辑后旧判断不得显示为当前结论。

## 验收数据与发布顺序

- 现有三题、所有已用于提示改进的题及其同型变体只能作为开发数据。下一批材料须先冻结题目、学生已学范围、判定规则、调用上限和失效条件，再看模型输出。
- 先取得不同课程、简单／中等／困难、选择／简答均覆盖的未见题；记录全部提交、生成失败、不可评、边界、模型分歧及费用缺项，不能只统计成功题。对自动返工候选和一组目标匹配的对照题，安排未看模型结果的独立教师逐题复核题目有效性、答案与难度。AI 教师式意见单列，不能伪作人类金标准。
- 先在正式服务运行**只记录决策**，测误返工、漏返工、保存前延迟、额外调用和失败恢复。通过预先约定的质量和预算门槛后，再在小范围开启一次返工；保留即时关闭开关。当前还没有可支持正式自动返工的独立准确率或可靠费用估计。

本文件是实现和验收协议，不表示已经开启自动返工。本地研究后端的旁路已于 2026-09-25 设为 `DIFFICULTY_SHADOW_MODE=off`；下述 R3、R4 等记录是关闭前有上限的真实验证调用。若未来重新启用，默认每任务最多两次旁路调用。
