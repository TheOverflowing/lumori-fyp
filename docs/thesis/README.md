## Rebuilding

Use the bundled Codex workspace Python runtime with python-docx, Pillow, ReportLab, pypdf and bundled Poppler. First run `scripts/build_thesis_visuals_v04.py` to rebuild deterministic module diagrams and charts (Graphviz is also required). Accepted image-assisted diagrams and live screenshots are retained assets, not regenerated by that script. Then run `scripts/build_thesis_report.py`; it reads `Manuscript.md`, the authoritative `references.json` and the checked `page_map.json`, then calls `scripts/build_thesis_figures.py` for original diagrams and the licensed crop. Render the DOCX with the documents skill's `render_docx.py --emit_pdf`, inspect every page, and copy the accepted PDF into `output/`. If pagination changes, update the contents and figure page map from the rendered PDF and render again.

Vector PDF companions preserve programmatic diagrams and charts for later reuse; image-assisted graphics remain raster assets. Their rendered versions are inserted into Word. The numerical ledger and original downloaded papers allow later verification. The build manifest records input/output hashes; it does not represent a new frozen runtime release. `build_thesis_review.py` serializes prior judgments and is not a fresh independent evaluation.

Institutional formatting and declarations remain to be confirmed against the official submission template.
