## Included changes

The snapshot includes per-question generation and review, request recovery, difficulty acceptance, optional query fusion and clarification, source exploration, document lifecycle controls, versioned ratings and Word/PDF export. Optional harness execution requires its separately configured runtime; it is not installed by the standard Docker image. The default remains the native runtime.

Deployment host configuration and the health endpoint are preserved in both repositories. Regression fixtures now respect the current three-round quality policy and exercise malformed JSON through the provider budget path instead of bypassing metering.

Research runs and thesis claims keep their original dates and limitations. This release does not rerun paid providers, parser model evaluation or learner studies. The thesis artifacts are archived unchanged, not regenerated by version management.

## Exclusions and recovery

Credentials, local account databases, uploaded user documents, model weights, virtual environments and temporary runtime stores remain excluded. Research benchmarks and frozen experimental outputs are retained only in the research repository. Before deploying, back up the existing data volume and local environment configuration. Reverting application code alone is not a database rollback.
