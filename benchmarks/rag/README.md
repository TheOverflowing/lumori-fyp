## 固定输入单位

每个 `documents` 元素就是一个完整 benchmark passage。本轮不得重新切分、合并、增加重叠或使用原应用的切块器。比较只索引 `document.text`，查询只使用 `query.text`，嵌入输入采用 `raw_text_v1_no_query_instruction`，不增加 query instruction 或自动翻译。

`title`、`topic`、`language`、`id` 是记录与分组用的元数据；`relevance`、`required_evidence_groups`、`annotation_note` 是评价标签。任何方法都不得把这些字段追加到检索输入，或用它们预筛正确主题。文档 ID 只用于关联记录，不作为相关性信号；同分按冻结输入顺序确定。

跨语言类别表示必要证据主要位于另一种语言的片段中，并不要求所有部分相关片段也必须是另一种语言。四种类别是主要信息需求标签，不意味着它们在语言或推理上完全互斥。多证据题的主标签优先于跨语言标签。

## 相关性与必要依据

`relevance` 是以文档 ID 为键的 qrels：

- `2`：直接支持答案中一个必需部分，可能单独充分，也可能需要与其他片段组合。
- `1`：对回答有实质性帮助，但只有部分依据或解释背景，不能独立满足必要要求。
- 未列出：当前标注为 `0`，并不表示已经由独立专家穷尽确认不相关。

每题 `annotation_note` 说明为什么需要这些依据，并区分完整支持和部分支持。高度相关的补充片段也纳入 qrels；仅属于相同大主题不构成相关性。例如并发隔离的介绍不能替代未提交事务回滚的依据。

`required_evidence_groups` 采用二维数组，每一组是必须找到的一个答案部分，组内任一片段都可以提供该部分。例如 `[["a", "b"], ["c"]]` 表示需要 `a` 或 `b` 中至少一个，并且需要 `c`；不能把两个可互换来源都误算成必要条件。本版现有必要组均使用一个明确的直接来源，保留组内替代语义以支持之后经人工确认的版本。

Passage Recall 统计所有正相关 qrels 的覆盖，包括 grade 1；Evidence Coverage 统计必要组覆盖；All-evidence Success 要求全部必要组都命中。三者不能互换。不可答查询的 qrels 和必要组均为空，不把其 Recall 定义成 1，也不把“所有空组都命中”的逻辑真值当成成功。

## 划分与使用限制

按 `family_id` 划分相关信息需求，同一需求的单问和综合变体留在同一 split；没有把同一问题的直接翻译放到另一 split。29 个信息需求 family 在两个 split 之间不重叠。不过所有方法仍检索同一组 40 个片段，因此这不是章节隔离，也不是对未见课程的泛化测试。

本轮在看结果前固定全部方法参数，只把 dev 用于软件健全性与诊断，test 用于一次预设比较。小规模自编数据的词汇、主题和 qrels 存在共同作者偏差；query-level 置信区间仅作探索，不具有正式样本设计所支持的总体解释。人工审核者应在看排名之前检查事实、可答性、qrels、部分相关来源和必要组，并记录分歧。

冻结后不要修改本文件中的 `pilot_v1.json`，即使发现某个方法失利或标注有遗漏。先记录问题；要修订标注或输入，创建新版本数据和变更说明，重新计算 SHA，并把旧结果保留。未来论文应另建具有使用权限的真实计算机课程资料集和人工标注；切片策略比较另开实验版本，避免将切片改动与召回方法差异混为一谈。
