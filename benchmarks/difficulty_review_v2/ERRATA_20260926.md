# 2026-09-26 开发集勘误：快递网络参考答案中的加和错误

## 错误与证据

冻结集 `cases.json` 的开发题 `courier_single_failure` 有两处参考文本错误：

| 字段 | 原文 | 校正 |
|---|---|---|
| `reference_answer` | `只能走S-A-T与S-B-T，费用9。` | `只能走S-A-T与S-B-T，费用10。` |
| `reference_explanation` | `只能选S-A-T和S-B-T，总费9；` | `只能选S-A-T和S-B-T，总费10；` |

原始图给定 `S-A:1`、`A-T:4`、`S-B:2`、`B-T:3`，所以两条直达支路的费用分别是 `1+4=5` 和 `2+3=5`，合计 **10**。题目要求的最优费用仍是 **8**：`S-A-C-T` 费用为 `1+1+1=3`，`S-B-T` 费用为 `2+3=5`，两条路径不共用走廊。枚举全部简单路径得到 10 条路径、9 组不共用走廊的路径对；最优路径对只有这一组。

旧参考文本包含可确认的算术错误，因此该题原先 `expected.content_status=pass` 的开发预期有误。模型指出这处加和错误并据此判定 `content_issue`，应被记录为有效内容检出，不能因旧预期为 pass 而称其为误拒。原有题面仍有解；这不意味着应把题目本身改判为 `invalid_question`。旧运行的原始指标保留原样，解释与报告须注明此勘误。

## 可执行复核

在仓库根目录运行以下代码。它直接从原冻结题目的来源文本读取边权，核对直达支路的加和，并枚举所有边不相交的简单路径对，不使用模型结果：

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python - <<'PY'
import itertools
import json
from pathlib import Path
import re

data = json.loads(Path('benchmarks/difficulty_review_v2/cases.json').read_text())
case = next(c for c in data['cases'] if c['id'] == 'courier_single_failure')
source = next(s['text'] for s in case['sources'] if s['id'] == 'courier_map')
edges = {frozenset((a, b)): int(w)
         for a, b, w in re.findall(r'([SABCT])-([SABCT]):(\d+)', source)}

def cost(route):
    return sum(edges[frozenset(edge)] for edge in zip(route, route[1:]))

paths = []
def visit(route):
    if route[-1] == 'T':
        used = {frozenset(edge) for edge in zip(route, route[1:])}
        paths.append((route, cost(route), used))
        return
    for edge in edges:
        if route[-1] in edge:
            next_station = next(iter(edge - {route[-1]}))
            if next_station not in route:
                visit(route + [next_station])

visit(['S'])
pairs = [(a[1] + b[1], a[0], b[0])
         for a, b in itertools.combinations(paths, 2) if not a[2] & b[2]]
assert cost(['S', 'A', 'T']) == 5
assert cost(['S', 'B', 'T']) == 5
assert cost(['S', 'A', 'T']) + cost(['S', 'B', 'T']) == 10
assert len(paths) == 10 and len(pairs) == 9
assert min(total for total, _, _ in pairs) == 8
optimal = [(a, b) for total, a, b in pairs if total == 8]
assert len(optimal) == 1
print('Direct routes: 5 + 5 = 10')
print('Simple paths:', len(paths), 'Disjoint pairs:', len(pairs))
print('Minimum fee: 8; unique optimal pair:', optimal[0])
PY
```

这段有限枚举验证的是当前小图的算术及最优值，不是对评委准确率或教师难度一致性的验证。
